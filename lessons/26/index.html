Урок 2: Развертывание среды на ПК и мобильных устройствах

Развертывание ИИ-ассистента возможно в двух независимых средах: полноценный интерфейс командной строки (CLI) для персональных компьютеров и изолированная песочница в виде официального приложения для мобильных устройств.

Инсталляция на ПК (macOS и Ubuntu)

Инсталляция на десктопные системы обеспечивает максимальный уровень контроля и интеграции в рабочие процессы. Процесс требует наличия среды выполнения Node.js. Установка выполняется с помощью защищенного детерминированного скрипта в терминале:

curl -fsSL https://claude.ai/install.sh | bash

Верификационные команды на ПК

Для математически точной валидации успешной инсталляции в терминале необходимо выполнить проверочные команды:

claude --version     # Проверка версии установленной сборки
which claude         # Подтверждение корректности системного пути ($PATH)
claude /login        # Инициация защищенного OAuth-туннеля

Инсталляция на мобильных устройствах (iOS и Android)

Мобильный клиент позволяет использовать мощности ИИ без сложных настроек терминального окружения (таких как Termux). Процесс установки сведен к базовому алгоритму взаимодействия с официальными маркетплейсами. Архитектура приложения обеспечивает нативный доступ к облачным API Anthropic, автоматически управляя шифрованием данных.

iOS

Перейдите в App Store, введите в поиск "Claude by Anthropic". Инициируйте загрузку. Требуется iOS 15.0+.

Android

Откройте Google Play Market. Найдите приложение "Claude". Для предотвращения фишинга убедитесь, что издатель — Anthropic PBC. Нажмите "Установить".

    Практические задания

  • **Установка Node.js**: На ПК выполните команду установки Node.js, а затем установите CLI-версию Claude через предоставленный bash-скрипт.

    • 2. **Проверка инсталляции**: На ПК запустите проверочные команды (claude --version, which claude) и задокументируйте результаты вывода терминала.

    3. **Проверка издателя**: На смартфоне найдите официальное приложение Claude в маркетплейсе (App Store / Google Play) и сверьте имя издателя.

    4. **Авторизация**: Пройдите процедуру авторизации в выбранной среде (через команду claude /login на ПК или внутри мобильного приложения).

    5. **Тестовый запрос**: Отправьте первый тестовый запрос (например, "Рассчитай корень из 144") для верификации сетевого соединения с серверами.
