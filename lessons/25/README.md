# Урок 25: Фундаментальная логика и математика ИИ-ассистентов

Для полноценного понимания работы современных ИИ-систем, таких как Claude, необходимо отойти от концепции "магического оракула" и рассмотреть систему как строгую математическую модель предсказания вероятностей. В основе работы языковой модели лежит механизм трансформации текста в числа — токенизация.

## Математическая модель

Текст разбивается на базовые единицы (токены). В среднем для английского языка 1 токен ≈ 0.75 слова, для русского языка соотношение может достигать 1 токен ≈ 0.4 слова из-за сложности морфологии. Модель рассчитывает вероятность появления следующего токена на основе всех предыдущих (контекста). Это можно выразить функцией вероятности P(w_t | w_1, w_2, ..., w_t-1).

## Архитектурный цикл

Архитектурно процесс общения с ИИ представляет собой "агентный цикл" (Agentic Loop). Пользователь выступает инициатором (Perception), формулирует задачу (Planning), ИИ генерирует ответ (Action), а пользователь оценивает результат (Observation). Вычислительная сложность механизма внимания (Attention Mechanism) внутри ИИ растет квадратично — O(N^2) относительно длины текста, что делает критически важным навык лаконичного изложения мыслей.

## Практические задания

1. **Токенизация**: Рассчитайте, сколько токенов примерно займет текст на русском языке объемом в 1000 слов.

2. **Логика вычислений**: Опишите логическую цепочку вычислений, которую производит модель при продолжении фразы "Два плюс два равно...".

3. **Алгоритмическая сложность**: Сформулируйте своими словами, почему длинные диалоги заставляют ИИ работать медленнее (опираясь на алгоритмическую сложность O(N^2)).

4. **Агентный цикл**: Напишите пример того, как человек выполняет роль "наблюдателя" в агентном цикле.

5. **Декомпозиция задач**: Составьте список из 5 профессиональных задач, которые можно декомпозировать (разбить на шаги) для решения с помощью ИИ.

## Ключевые концепции

- **Токенизация** — преобразование текста в числовые векторы
- **Вероятностное предсказание** — ИИ не "знает" ответ, а предсказывает вероятность
- **Контекстное окно** — объем информации, который может обработать модель
- **Агентный цикл** — итеративный процесс взаимодействия человека и ИИ
