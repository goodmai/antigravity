# Урок 27: Управление диалогом и логика промпт-инжиниринга

Диалог с моделью — это изолированный "контекстный контейнер". Независимо от того, используете ли вы мобильное приложение или консоль ПК, логика работы с памятью одинакова.

## Структура контекста в диалоге

Каждый раз, когда вы отправляете сообщение, система берет ВСЮ предыдущую переписку в текущем чате, приклеивает к ней ваш новый вопрос и отправляет этот текстовый массив (вектор) на сервера. Это означает, что чем дольше длится чат, тем больше вычислительных ресурсов (токенов) расходуется. Логический эквивалент команды `/clear` (на ПК) — это создание нового чата (на смартфоне). Это обнуляет матрицу внимания ИИ, предотвращая смешивание тем.

## Структура эффективного промпта

Промпт-инжиниринг опирается на строгую структуру. Эффективный запрос должен содержать:

1. **Роль** — например, "Действуй как математик"
2. **Задачу** — "Реши уравнение"
3. **Контекст** — "Уравнение из области линейной алгебры"
4. **Формат вывода** — "Ответ дай по шагам"

Такая декомпозиция снижает энтропию ответов модели.

## Пример структурированного промпта

```
Роль: Выступай в роли опытного Python-разработчика
Задача: Напиши функцию для сортировки списка
Контекст: Функция должна работать с массивом целых чисел до 1000 элементов
Формат: Дай код с объяснением построчно
```

## Практические задания

1. **Очистка контекста**: Создайте новый чат (или введите `/clear` на ПК). Логически объясните, почему это действие аналогично очистке оперативной памяти.

2. **Структурированный промпт**: Напишите промпт, состоящий из 4 элементов (Роль, Задача, Контекст, Формат вывода), и отправьте его Claude.

3. **Эксперимент с контекстом**: Проведите эксперимент — задайте один вопрос в очень длинном чате и его же в совершенно новом. Сравните точность ответов.

4. **Формат вывода**: Сформулируйте математическую задачу и попросите ИИ решить ее, указав формат вывода "только итоговая цифра, без пояснений".

5. **Анализ роли**: Проанализируйте, почему добавление роли меняет структуру токенов в ответе.

## Когда использовать `/clear`

- Переход к совершенно новой теме
- Если диалог стал слишком долгим (>50 сообщений)
- Когда нужно сбросить введенные ранее правила/роли
- Для оптимизации стоимости и скорости обработки

## Типичные ошибки в промпт-инжиниринге

❌ **Плохо**: "Напиши код"
✅ **Хорошо**: "Напиши Python-функцию для фильтрации списка дубликатов. Входные данные: список строк. Выходные данные: JSON с чистыми значениями. Объясни логику."

❌ **Плохо**: "Реши задачу по матану"
✅ **Хорошо**: "Реши интеграл ∫(2x+3)dx с пояснением каждого шага. Формат: пошаговое решение."
