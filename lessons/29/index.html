Урок 5: Анализ данных и границы безопасности песочницы

Агент поддерживает мультимодальность — способность обрабатывать не только текстовые векторы, но и визуальные данные (фотографии, графики). Матрица пикселей преобразуется в векторное представление, которое нейросеть анализирует на наличие паттернов.

Безопасность: Constitutional AI

В архитектуру встроена система Constitutional AI. Любой запрос проходит через фильтры-классификаторы. Если вероятность нарушения "конституции" (этических и логических аксиом) превышает заданный порог, функция активации блокирует ответ.

Различия безопасности между платформами

Интерфейс мобильного приложения и ПК-версия имеют разные допуски:

CLI на ПК (максимальный контроль)

  • Агент может читать и редактировать файлы вашей системы
  • Требует вашего подтверждения (y/n) для каждой операции
  • Полный доступ к системным ресурсам (с ограничениями)
  • Идеален для разработки и автоматизации

    • Мобильное приложение (строгая изоляция)

  • Работает в режиме строгой песочницы (Sandbox)
  • Без доступа к файловой системе смартфона
  • Математически безопасна для устройства пользователя
  • Идеальна для конфиденциальности данных

    • Мультимодальные способности

    Claude может обрабатывать:

  • **Текст** — основной формат

    • 2. **Изображения** — фотографии, скриншоты, графики

    3. **PDF-документы** — извлечение текста и анализ структуры

    4. **Диаграммы** — распознавание паттернов и связей

    Процесс анализа изображения

    Изображение → Токенизация пикселей → Векторное представление 
             → Анализ паттернов → Извлечение информации
             → Языковой ответ

    Этические границы Constitutional AI

    Модель отказывает в:

  • Помощи с нелегальной деятельностью
  • Генерации контента для дезинформации
  • Созданию вредоносного кода с очевидным назначением
  • Нарушении приватности других лиц
  • Сексуализации несовершеннолетних
  • Подробных инструкций по причинению вреда

    • Однако может помочь в:

  • Образовательных целях (понимание уязвимостей)
  • Исторических анализах
  • Безопасности и защите (CTF, пентесты с разрешением)

    Практические задания

  • **Чтение файла на ПК**: На ПК создайте текстовый файл, попросите Claude (CLI) прочитать его и убедитесь, что система запрашивает подтверждение.

    • 2. **Анализ графика**: Загрузите скриншот с математическим графиком и попросите ИИ извлечь из него числовые данные в виде списка.

    3. **Тестирование безопасности**: Сформулируйте заведомо некорректный запрос и проанализируйте стандартный ответ фильтра безопасности (Constitutional AI).

    4. **Сравнение архитектур**: Опишите логическими терминами, почему мобильное приложение (песочница) концептуально отличается от CLI на ПК.

    5. **Мультимодальный анализ**: Попросите ИИ перевести текст с фотографии на другой язык, оценив объединение визуального парсинга и перевода.

    Защита личных данных

  • **На ПК**: Будьте осторожны при запросе на чтение файлов из ~/ с конфиденциальной информацией
  • **На мобильном**: Приложение не может получить доступ к контактам, фото галереи или файлам — только к тому, что вы явно скопируете в текст
  • **В облаке**: Запросы и ответы обрабатываются безопасно, но не забывайте о приватности
