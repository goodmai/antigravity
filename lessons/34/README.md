# Урок 34: Разработка под Android через Android CLI 1.0

С выходом стабильной версии **Android CLI 1.0**, разработка мобильных приложений стала доступна напрямую через терминал, что открывает огромные возможности для автономных агентов. Теперь агент может не просто писать код, но и взаимодействовать с внутренними механизмами Android Studio, проводить глубокий анализ и даже рендерить превью интерфейсов.

---

## 📱 Что такое Android CLI?

**Android CLI** — это легковесный интерфейс, который служит мостом между разработчиком (или ИИ-агентом) и экосистемой Android. Он позволяет выполнять задачи сборки, тестирования и анализа без необходимости постоянного взаимодействия с тяжелым GUI Android Studio.

### Основные возможности:
- **Интеграция с Android Studio**: Команда `android studio` позволяет агенту использовать семантический поиск, поиск деклараций и статический анализ IDE.
- **Библиотека навыков (Skills)**: Специализированные наборы инструкций для миграции (например, на CameraX), адаптивного UI и настройки тестирования.
- **Journeys (Путешествия)**: Сценарии на естественном языке для автоматизации тестирования пользовательского опыта.

---

## 🛠 Основные команды

### Настройка окружения
```bash
# Инициализация среды и установка базовых навыков
android init

# Обновление CLI до последней версии
android update
```

### Интеграция с IDE (под капотом)
Когда проект открыт в Android Studio, агент может использовать следующие команды для "понимания" кода:

- `android studio analyze-file <path>`: Запуск инспекций IDE для поиска ошибок и варнингов.
- `android studio find-declaration <symbol>`: Точный поиск определения класса или метода.
- `android studio render-compose-preview`: Рендеринг Jetpack Compose UI и получение пути к изображению и иерархии элементов.
- `android studio version-lookup`: Поиск последних версий зависимостей в Google Maven.

## 🤖 Агентная разработка под Android

Для Antigravity новый Android CLI доступен в виде бандла плагинов. Это позволяет агенту:
1. **Создавать проекты**: Использовать шаблоны через `android init`.
2. **Исправлять ошибки**: Анализировать логи компиляции и результаты `analyze-file`.
3. **Проектировать UI**: Рендерить превью Compose и корректировать верстку на основе "увиденного" (через визуальные сабагенты).

---

## 🧪 Задания для закрепления

1. **Инициализация**: Запустите `android init` в пустой директории и изучите созданную структуру.
2. **Анализ кода**: Используйте `android studio analyze-file src/main/java/MainActivity.kt` для проверки качества кода.
3. **Поиск зависимостей**: Проверьте актуальную версию библиотеки Compose через `android studio version-lookup androidx.compose.ui:ui`.
4. **Визуализация**: Попробуйте отрендерить превью любого Compose-компонента через `android studio render-compose-preview`.
5. **Skill Management**: Добавьте навык адаптивного UI командой `android skills add --skill="Adaptive UI"`.
