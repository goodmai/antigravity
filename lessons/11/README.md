# Урок 11: Терминал, Безопасность и Режим Turbo

Antigravity предоставляет агенту доступ к терминалу, что делает его мощным инструментом, но требует строгих мер безопасности.

---

## 🛡️ Три режима работы с терминалом

1.  **Off (Ручной)**: Агент только предлагает команды. Вы копируете и выполняете их сами. Для параноидальной безопасности.
2.  **Auto (Интеллектуальный)**:
    - Безопасные команды (`ls`, `cat`, `echo`) выполняются молча.
    - Опасные (`rm`, `docker system prune`) требуют вашего подтверждения.
3.  **Turbo (Автономный)**: Агент выполняет всё, кроме явно запрещенных команд. Для максимальной скорости.

---

## ⛔ Списки безопасности (Allow/Deny Lists)

Даже в режиме Turbo агент ограничен списками:

- **Deny List (Черный список)**: Команды, заблокированные **всегда**.
  - _Пример_: `rm -rf /`, отправка данных на неизвестные IP.
- **Allow List (Белый список)**: Команды, разрешенные без подтверждения.
  - _Пример_: `npm test`, `git status`.

---

## 🚀 Режим Turbo: Баланс риска и скорости

Режим Turbo идеален для массового рефакторинга.

- _Сценарий_: "Замени во всех 500 файлах старый логгер на новый".
- _Риск_: Ошибка агента может испортить много файлов.
- _Защита_: Используйте Turbo только в чистом git-дереве, чтобы всегда можно было сделать `git reset`.

---

## ⌨️ Inline Commands

Используйте `Cmd+I` (macOS) или `Ctrl+I` (Win/Lin) в терминале для генерации команд на естественном языке.

> **Пример**: _"Найди все файлы логов, измененные за час, и покажи ошибки 500"_
> -> Агент сгенерирует сложный `find ... | grep ...` скрипт.

## 🔬 Как это работает глубже

Решение «выполнять или спросить» принимается по конвейеру:

```
команда → нормализация → Deny List? ──да──▶ блок (всегда)
                              │нет
                       Allow List? ──да──▶ выполнить молча
                              │нет
                    режим Turbo? ──да──▶ выполнить
                              │нет (Auto)
                  потенциально опасна? ──да──▶ запросить y/n
                              │нет
                          выполнить
```

Deny List имеет абсолютный приоритет — он срабатывает **до** Turbo. Поэтому
даже автономный режим не может выполнить запрещённую команду. Allow List —
это «доверенная рутина», которая ускоряет цикл, не снижая безопасность.

## ⚠️ Типичные ошибки

- **Turbo на грязном git-дереве.** Нет точки отката — ошибка агента
  необратима. Всегда начинай с чистого `git status`.
- **Слишком широкий Allow List.** `rm`, `curl | bash`, `git push --force`
  в белом списке = дыра в безопасности.
- **Пустой Deny List.** Минимум: `rm -rf /`, fork-bomb, отправка данных на
  внешние адреса.
- **Inline-команды без проверки.** Сгенерированный `find | xargs` стоит
  прочитать перед запуском.

## 🧠 Ключевые концепции

- **Off / Auto / Turbo** — компромисс «контроль ↔ скорость».
- **Deny List** — абсолютный запрет, приоритет над всем.
- **Allow List** — доверенная рутина без подтверждений.
- **Чистое git-дерево** — обязательная страховка для Turbo.
