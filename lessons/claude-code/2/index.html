Lesson 2: Installation & Configuration

Getting Claude Code running takes about five minutes. You need Node.js ≥18, an Anthropic API key, and a terminal.

Installation via npm

npm install -g @anthropic-ai/claude-code

This installs the claude command globally. Verify with:

claude --version

API Key Setup

Claude Code authenticates via your Anthropic API key. The recommended approach is to set the environment variable:

export ANTHROPIC_API_KEY=sk-ant-...

Add this to your ~/.bashrc or ~/.zshrc to persist it across sessions. Alternatively, run claude and it will prompt you to enter a key on first launch.

First Run

cd your-project
claude

This opens an interactive session in your terminal. Claude Code reads the current directory and is ready for instructions.

Global vs Project Settings

Settings live in two locations:

  • ~/.claude/settings.json — global defaults applied to every project
  • .claude/settings.json (in your project root) — project-level overrides

Project settings take precedence over global settings. Both use the same JSON schema.

Key Settings

{
  "model": "claude-sonnet-4-6",
  "permissions": {
    "allow": ["Bash(git *)", "Read(**)", "Edit(**)"],
    "deny": ["Bash(rm -rf *)"]
  }
}

Practical Exercises

Complete all three tasks to confirm your installation is production-ready:

  1. Install and verify. Run npm install -g @anthropic-ai/claude-code, then export ANTHROPIC_API_KEY and confirm claude --version prints the version. Add the export to your ~/.bashrc or ~/.zshrc so it persists across sessions.
  2. Explore the CLI surface. Run claude --help and write down at least three flags you would actually use day-to-day (for example --model, --print, --continue). For each, jot a one-line note on when you'd reach for it.
  3. Author a project settings file. Create .claude/settings.json in a test project that allows all git subcommands plus Read and Edit, but denies rm -rf *, git push --force, and any curl … | bash pattern. Start Claude in that project and ask it to run git status; confirm it executes without prompting.
  4. Global vs project precedence. Add a different model setting to ~/.claude/settings.json and a competing one to .claude/settings.json. Run /status inside the project and verify the project-level value wins.
