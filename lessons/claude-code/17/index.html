Lesson 17: Multi-model Strategies

Anthropic's Claude family — Opus, Sonnet, Haiku — offers different capability/cost tradeoffs. Effective agents route tasks to the right model for the job.

Model Comparison

ModelCapabilitySpeedCostBest for
Opus 4.7HighestSlowestHighestComplex reasoning, architecture decisions
Sonnet 4.6HighFastMediumMost coding tasks, code review
Haiku 4.5GoodFastestLowestSimple tasks, classification, formatting

Switching Models in CLI

/model claude-opus-4-7
/model claude-sonnet-4-6
/model claude-haiku-4-5-20251001

Task-Based Routing

In the SDK, route by task type:

function selectModel(task: string): string {
  if (task.includes('architect') || task.includes('design')) {
    return 'claude-opus-4-7';
  }
  if (task.includes('format') || task.includes('rename')) {
    return 'claude-haiku-4-5-20251001';
  }
  return 'claude-sonnet-4-6';
}

Cost Optimization

  • Use Haiku for the "triage" phase (classify what type of task this is)
  • Use Sonnet for the "execution" phase (write the code)
  • Use Opus only when Sonnet fails or for architectural review
  • Enable prompt caching to reduce repeated context costs by up to 90%

Fast Mode

Claude Code's /fast toggle switches to an optimized inference mode. Use it for rapid iteration when you don't need maximum quality.

Practical Exercise

Design a two-stage agent pipeline: first use Haiku to classify an incoming task as "simple" or "complex", then route to Sonnet or Opus accordingly. Implement it and test with 5 example tasks, measuring cost versus a single-model approach.
