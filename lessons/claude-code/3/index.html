Lesson 3: First Prompts & Basic Commands

Once Claude Code is running, you interact with it via natural language — but knowing a handful of slash commands and keyboard shortcuts makes the experience dramatically more efficient.

Asking Questions

Type any natural language request at the prompt. Claude Code understands context from your current directory:

> What does this project do?
> Find all TODO comments in the codebase
> Explain the function in src/auth.js

File Operations

Claude Code can read and edit files on request:

> Read the README.md file
> Add input validation to the login function in src/auth.js
> Create a new file called utils/format.js with a date formatter

Slash Commands

CommandDescription
/helpShow all available commands and shortcuts
/clearClear conversation history (start fresh)
/compactSummarize conversation to free context space
/modelSwitch the active Claude model
/statusShow current session stats (tokens, cost)
/quitExit Claude Code

Keyboard Shortcuts

  • Ctrl+C — interrupt the current action (stops tool execution)
  • Ctrl+L — clear screen
  • Up/Down arrows — navigate command history
  • Esc — cancel current input

Tips for Effective Prompting

  • Be specific about file paths: "edit src/auth.js" not "edit the auth file"
  • State expected outcomes: "refactor to use async/await and keep all tests passing"
  • Use /clear between unrelated tasks to avoid context bleed

Practical Exercises

Complete all three tasks in a single Claude Code session in a project you own:

  1. Project orientation. Ask Claude to "summarize this project's structure in 5 bullet points, including the tech stack, entry point, and test command." Confirm Claude reads files (not just guesses) by checking that it cites real filenames in the answer.
  2. Targeted edit. Pick one small, well-scoped change — for example "add input validation to the function in src/utils/parse.js" or "rename variable foo to userId in src/auth.js". Give Claude the exact file path and the expected outcome. Review the diff before accepting.
  3. Use the slash commands. Run /status to see token usage so far, then /compact to summarize the conversation, and finally /clear to start fresh. Compare the token count from /status before and after compaction — note the reduction in your own words.
  4. Keyboard shortcut drill. Start a long-running command, press Ctrl+C to interrupt it, then use the Up arrow to recall your previous prompt and rephrase it. Practice this loop until it feels automatic.
