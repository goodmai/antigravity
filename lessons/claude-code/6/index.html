Lesson 6: MCP Servers

Model Context Protocol (MCP) is an open standard that lets Claude Code connect to external services — databases, APIs, project management tools — as if they were first-class tools. MCP turns Claude Code from a local coding assistant into an integrated platform agent.

What is MCP?

MCP defines a client-server protocol where:

  • MCP servers expose tools, resources, and prompts
  • Claude Code (client) discovers and calls those tools automatically

Popular MCP servers include: GitHub, Slack, Linear, PostgreSQL, filesystem, browser automation, and more.

Adding an MCP Server

MCP servers are configured in .claude/settings.json (project-scope) or ~/.claude/settings.json (global):

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "${GITHUB_TOKEN}"
      }
    }
  }
}

Scoping

  • Global MCP servers are available in all projects
  • Project MCP servers only activate when in that project directory
  • Project config overrides global config for the same server name

Using MCP Tools

Once configured, MCP tools appear alongside native tools. You can ask Claude naturally:

> Create a GitHub issue for the login bug we just found
> What are the open Linear tickets in the current sprint?
> Query the database for all users registered this week

Debugging MCP Connections

  • Use claude --mcp-debug to see MCP server startup logs
  • Check that required environment variables are set
  • Verify the MCP server package is installed: npx -y server-name --version

Practical Exercises

Complete all three tasks to confirm MCP is wired up end-to-end:

  1. Connect a filesystem MCP server. Add the official @modelcontextprotocol/server-filesystem entry to your global ~/.claude/settings.json, scoped to a specific directory (e.g., ~/Documents). Restart Claude and confirm the MCP tools appear in /mcp output.
  2. Compare native vs MCP tools. In the same session, ask Claude to "list the files in ~/Documents using the MCP filesystem tool", then "do the same using the native Read tool". Note the differences — which tool returns directory metadata, which respects .gitignore, which is faster for large trees.
  3. Add a second server with secrets. Add the GitHub MCP server with a GITHUB_TOKEN environment variable. Verify by asking Claude to "list the open issues on my X repository". If it fails, run claude --mcp-debug and trace the startup log to identify the root cause.
  4. Scope to a project. Move the GitHub MCP server from global to project-level .claude/settings.json. Open a different project and confirm the server is not active there. Project-level scoping is the key habit for limiting blast radius.
