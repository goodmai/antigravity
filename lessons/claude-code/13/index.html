Lesson 13: Context Management

Every Claude model has a context window — the maximum amount of text it can process in one request. Effective context management keeps your sessions accurate, fast, and cost-efficient as conversations grow long.

Understanding the Context Window

Claude Sonnet 4.6 supports a 200,000-token context window. At roughly 750 words per 1,000 tokens, that's about 150,000 words — enough for a long conversation or a moderately large codebase. But context has a cost: processing more tokens is slower and more expensive.

The /compact Command

When your session grows long, use /compact:

/compact

Claude summarizes the conversation history, compressing it significantly while preserving key facts, decisions, and file states. The summary replaces the raw history in context.

CLAUDE.md Scoping

CLAUDE.md files are injected at session start. Keep them focused:

  • Remove outdated information promptly
  • Use subdirectory CLAUDE.md files for module-specific context
  • Don't put the entire codebase in CLAUDE.md — link to key files instead

Token-Efficient Prompting

  • Reference files by path instead of pasting their content: "look at src/auth.js"
  • Ask for summaries rather than full rewrites when possible
  • Use /clear between unrelated tasks
  • Structure prompts as bullet points rather than paragraphs

.claudeignore

Like .gitignore, .claudeignore tells Claude Code what to skip when indexing your project:

node_modules/
dist/
*.log
*.lock
coverage/

Practical Exercises

Complete all three tasks to keep long sessions efficient:

  1. Measure compaction. Start a Claude Code session and run several substantial tasks (reading files, generating code) until /status shows you've used 50% or more of the context window. Run /compact, then check /status again. Note the before/after token counts and what information survived the compression.
  2. Write a .claudeignore. In a real project, add .claudeignore that excludes node_modules/, dist/, coverage/, lockfiles, and large fixture/data directories specific to that project. Confirm Claude no longer reads those paths when you ask "what files are in this project?".
  3. Reference vs paste. Pick a 500-line file. Run the same task twice: once by pasting the entire file into the prompt, and once by saying "look at path/to/file.ts". Compare the token usage between the two approaches — the difference is the cost of bad context hygiene.
  4. Tighten CLAUDE.md. Open your project CLAUDE.md and remove or shorten one section that has become stale or verbose. Measure session start cost (/status on a fresh session) before and after.
