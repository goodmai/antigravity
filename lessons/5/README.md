# Урок 5: Каталог стандартных скиллов (17 / 17)

> В директории `skills/` репозитория Antigravity лежит **17 готовых скиллов**. В этом уроке — карта каталога, типовые промпты, тесткейсы и комбинации скиллов друг с другом.

---

## Как читать карточку скилла

Каждый скилл описан по шаблону:

- **Назначение** — одна строка, что он делает.
- **Промпт** — пример формулировки, на которой скилл активируется.
- **Результат** — что появится в `artifacts/`.
- **Юзеркейсы** — где применять в проде.
- **Тесткейс** — как убедиться, что скилл отработал корректно.

## 🎨 Группа A. Визуальное искусство и дизайн

### 1. `algorithmic-art`
- **Назначение:** генеративное искусство на p5.js.
- **Промпт:** «Создай генеративное искусство на тему «Биолюминесценция»».
- **Результат:** интерактивный `art.html` с управляющими слайдерами.
- **Юзеркейсы:** динамические фоны лендингов, заставки конференций.
- **Тесткейс:** изменение `seed` через UI должно менять рисунок без перезагрузки.

### 2. `canvas-design`
- **Назначение:** статические постеры/иллюстрации в `.png`/`.pdf`.
- **Промпт:** «Сделай постер «Geometric Silence» формата A2».
- **Результат:** `poster.png` 300 dpi.
- **Юзеркейсы:** печатная продукция, обложки докладов.
- **Тесткейс:** в PNG нет наложений текста на ключевые графические элементы.

### 3. `brand-guidelines`
- **Назначение:** применение брендбука Anthropic.
- **Промпт:** «Оформи документ в стиле Anthropic».
- **Результат:** документ с шрифтовой парой Poppins/Lora и корпоративной палитрой.
- **Юзеркейсы:** корпоративные отчёты, презентации для клиента.
- **Тесткейс:** все hex-цвета совпадают с эталоном `resources/palette.json`.

### 4. `frontend-design`
- **Назначение:** боевые UI-интерфейсы без «AI-слопа».
- **Промпт:** «Спроектируй футуристичный дашборд управления дронами».
- **Результат:** React/HTML/CSS с адаптивной сеткой и анимациями.
- **Юзеркейсы:** прототипы продукта, лендинги.
- **Тесткейс:** Lighthouse Accessibility ≥ 90, нет горизонтального скролла на 360 px.

### 5. `theme-factory`
- **Назначение:** 10 пресетных тем (Ocean, Forest, Cyber и т. д.).
- **Промпт:** «Примени тему «Ocean Depths» к презентации».
- **Результат:** обновлённый CSS-токен-сет.
- **Юзеркейсы:** быстрая стилизация артефактов под бренд.
- **Тесткейс:** контраст текст/фон ≥ 4.5 : 1 (WCAG AA).

### 6. `slack-gif-creator`
- **Назначение:** GIF-эмодзи под лимиты Slack.
- **Промпт:** «Сделай пульсирующую звезду 128×128 для Slack».
- **Результат:** `star.gif` ≤ 128 KB.
- **Юзеркейсы:** кастомные реакции в командных каналах.
- **Тесткейс:** `ffprobe star.gif` показывает 128×128, размер ≤ 128 KB.

## 📄 Группа B. Документы и офис

### 7. `doc-coauthoring`
- **Назначение:** структурированное соавторство (контекст → черновик → ревизия).
- **Промпт:** «Помоги написать ТЗ на платёжный шлюз».
- **Результат:** документ с разделами Goals / Non-goals / Risks.
- **Юзеркейсы:** PRD, RFC, инструкции.
- **Тесткейс:** пройдены все 3 стадии (есть commit-история черновиков).

### 8. `docx`
- **Назначение:** генерация и редактирование `.docx`.
- **Промпт:** «Сделай официальное письмо в Word».
- **Результат:** `letter.docx` со стилями Heading 1–3.
- **Юзеркейсы:** юридические документы, статьи.
- **Тесткейс:** `pandoc letter.docx -t plain` восстанавливает текст без потерь.

### 9. `pptx`
- **Назначение:** PowerPoint-презентации.
- **Промпт:** «Подготовь питч-дек продукта на 10 слайдов».
- **Результат:** `deck.pptx` с заголовками и спикер-нотами.
- **Юзеркейсы:** квартальные ревью, инвестпрезентации.
- **Тесткейс:** открытие в LibreOffice/PowerPoint без сломанных макетов.

### 10. `xlsx`
- **Назначение:** Excel-таблицы с формулами.
- **Промпт:** «Создай бюджет с формулами SUM по месяцам».
- **Результат:** `budget.xlsx` с рабочими ячейками.
- **Юзеркейсы:** финансовый учёт, чек-листы.
- **Тесткейс:** изменение исходных ячеек пересчитывает итог.

### 11. `pdf`
- **Назначение:** манипуляции с PDF (merge / split / extract).
- **Промпт:** «Объедини эти три PDF в один».
- **Результат:** `merged.pdf` с корректным оглавлением.
- **Юзеркейсы:** документообороот, сборка комплектов.
- **Тесткейс:** `pdftotext merged.pdf -` содержит текст всех исходников.

### 12. `internal-comms`
- **Назначение:** шаблоны внутренних коммуникаций (3P, FAQ, апдейты).
- **Промпт:** «Сформируй еженедельный 3P-апдейт».
- **Результат:** текст по формату Progress / Plans / Problems.
- **Юзеркейсы:** командные рассылки, статусы руководству.
- **Тесткейс:** структура совпадает с `examples/3p-template.md`.

## 🛠️ Группа C. Разработка и инструменты

### 13. `mcp-builder`
- **Назначение:** генерация MCP-серверов.
- **Промпт:** «Создай MCP-сервер для GitHub API».
- **Результат:** проект с `tools/`, `manifest.json`, тестами.
- **Юзеркейсы:** подключение новых API к агенту.
- **Тесткейс:** MCP Inspector видит сервер и его инструменты.

### 14. `skill-creator`
- **Назначение:** мастер по созданию новых скиллов.
- **Промпт:** «Создай скилл для ревью SQL-миграций».
- **Результат:** валидная папка `SKILL.md` + scripts + examples.
- **Юзеркейсы:** упаковка экспертизы команды.
- **Тесткейс:** `package_skill.py` отрабатывает с кодом 0.

### 15. `web-artifacts-builder`
- **Назначение:** сборка React + Tailwind + shadcn в один HTML.
- **Промпт:** «Собери дашборд аналитики в одном файле».
- **Результат:** `dashboard.html` с инлайн-CSS и JS.
- **Юзеркейсы:** интерактивные артефакты прямо в чате.
- **Тесткейс:** открытие в браузере без сетевых зависимостей.

### 16. `webapp-testing`
- **Назначение:** автотесты сайтов через Playwright.
- **Промпт:** «Проверь работоспособность кнопок на главной».
- **Результат:** `playwright.report` + скриншоты падений.
- **Юзеркейсы:** smoke-тесты, регрессия.
- **Тесткейс:** exit code 0, все спецификации зелёные.

### 17. `inspect-artifacts`
- **Назначение:** обзор папки артефактов текущего диалога.
- **Промпт:** «Покажи мои артефакты».
- **Результат:** дерево `.gemini/antigravity/brain/...`.
- **Юзеркейсы:** быстрый возврат к ранее сгенерированным файлам.
- **Тесткейс:** вывод содержит `task.md` и `walkthrough.md`, если они были.

## Комбинации скиллов (composability)

| Сценарий | Цепочка скиллов |
| :--- | :--- |
| Презентация под бренд клиента | `pptx` → `brand-guidelines` → `theme-factory` |
| Отчёт по проекту | `doc-coauthoring` → `docx` → `pdf` |
| Готовый лендинг | `frontend-design` → `web-artifacts-builder` → `webapp-testing` |
| Кастомный инструмент | `mcp-builder` → `skill-creator` → `inspect-artifacts` |

> [!TIP]
> Скиллы можно вызывать неявно: агент сам подберёт цепочку, если задача комплексная. Явное указание (`используй skills/pptx и skills/brand-guidelines`) полезно, когда нужна предсказуемость.

## Практические задания

> Все артефакты складывайте в `artifacts/lesson-5/task-N/`. Коммитьте отдельно по каждому заданию.

### Задание 1 — Generative art
Запросите `algorithmic-art` с темой «Северное сияние над Байкалом». Сохраните `art.html`. Откройте в браузере, измените `seed` через UI, сохраните второй скриншот. Объясните в `notes.md`, какие параметры дают наибольшее визуальное разнообразие.

### Задание 2 — Brand-pack
Возьмите свой текстовый README любого проекта. Прогоните через `brand-guidelines` и `theme-factory` с темой `Ocean Depths`. Сделайте до/после в `.docx`. Проверьте контрастность WCAG AA через DevTools.

### Задание 3 — Slide deck для урока 4
Используя `pptx` и `doc-coauthoring`, соберите 7-слайдовый питч-дек по уроку 4 (Agent Skills). Слайды: title / problem / structure / lifecycle / example / anti-patterns / call-to-action. Спикер-ноты обязательны.

### Задание 4 — Excel-чеклист скиллов
Сгенерируйте через `xlsx` таблицу с колонками `skill | category | status | last_tested_at | owner`. Заполните 17 строк. Добавьте формулу-счётчик «протестировано / всего» в шапку.

### Задание 5 — PDF-комплект
Объедините через `pdf` три артефакта из заданий 2, 3, 4 в один PDF. Добавьте обложку и оглавление. Проверьте через `pdftotext`, что текст всех исходников присутствует.

### Задание 6 — Web-артефакт + тесты
Через `web-artifacts-builder` сделайте интерактивный фильтр по каталогу 17 скиллов (поиск по группе и ключевому слову). Покройте `webapp-testing`-ом два сценария: «фильтр по группе A показывает 6 карточек», «поиск по слову `pdf` оставляет одну карточку».

### Задание 7 — Собственный скилл
Через `skill-creator` создайте новый скилл `daily-standup`, который формирует ежедневный апдейт из commit-сообщений за последние 24 часа. Опишите алгоритм, добавьте `scripts/collect_commits.py --help`, пример выхода в `examples/`. Сразу протестируйте на сегодняшних коммитах.
