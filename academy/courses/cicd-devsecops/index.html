CI/CD DevSecOps Mastery 🛡️

Курс «CI/CD DevSecOps Mastery» — путь от первого git push до подписанного мульти-арх контейнера, который деплоится через ArgoCD на EKS и Akash, бэкапится WAL-G, а падение SLO одновременно прилетает в Telegram, Slack и Discord. Каждый урок открыт песочницей: act + k3d + Gitea + Vault + LocalStack — без облака и без оплаты.

Sandbox-first. Любая команда сначала запускается локально: GH Actions через act, k8s через k3d, AWS через LocalStack, Vault через vault server -dev, Sigstore через self-hosted Rekor + Fulcio. Боевой облак — опционален.
Канон-источники. Курс выстроен по OWASP DSOMM/SAMM, NIST SSDF (SP 800-218), SLSA v1.0, CIS Benchmarks, Google SRE и FinOps Foundation. Полный список — в plan.md.
