Модуль III · Lesson 11 · viem · TypeScript · JSON-RPC

viem — PublicClient, WalletClient и type-safe контракты

→ переход из Модуля II (Solidity) в Модуль III (Frontend). Контракты у нас уже есть; теперь учимся к ним подключаться из JS/TS.

viem — современный TypeScript-клиент для EVM-цепей, созданный авторами wagmi (Tom Meagher, Jake Moxey). Ключевые преимущества над ethers.js: полная типизация ABI, tree-shaking, отсутствие BigNumber-объекта (используется нативный bigint), модульная архитектура, превосходящая производительность. С 2024 года — стандарт де-факто в новых dApp-стэках (Next.js + wagmi + viem).

Что вы получите. После урока вы умеете: создать PublicClient и читать любой контракт с typesafe ABI; создать WalletClient и подписывать/отправлять транзакции; декодировать события Transfer с типизированным args; рассчитать газ через estimateGas и estimateFeesPerGas; работать с multicall для батчинга чтений.

1. Архитектура viem

viem строится вокруг двух клиентов:

  • PublicClient — read-only клиент для JSON-RPC: блоки, состояние, логи, eth_call, eth_estimateGas. Не требует приватного ключа.
  • WalletClient — write-клиент: подписывает транзакции и сообщения. Подключается к источнику ключа: MetaMask, Ledger, raw private key, mnemonic. Внутри использует тот же transport, что и PublicClient.

Под обоими — Transport: HTTP, WebSocket, IPC, custom (например, EIP-1193 provider от MetaMask). Один transport может быть разделён двумя клиентами, что экономит ресурсы. 

import { createPublicClient, createWalletClient, http, custom } from 'viem'
import { mainnet, sepolia } from 'viem/chains'

// Read-only клиент для Sepolia
const publicClient = createPublicClient({
  chain: sepolia,
  transport: http('https://rpc.sepolia.org'),
})

// Write-клиент, использующий window.ethereum (MetaMask)
const walletClient = createWalletClient({
  chain: sepolia,
  transport: custom(window.ethereum),
})

// Базовые операции
const blockNumber = await publicClient.getBlockNumber()
console.log('Sepolia block:', blockNumber)             // bigint

const [address] = await walletClient.getAddresses()   // adress: 0x...
const balance   = await publicClient.getBalance({ address })
console.log('Balance:', balance, 'wei')               // bigint

2. Type-safe ABI и readContract

Главная супер-сила viem — типизация ABI прямо из импортированного JSON. TypeScript видит структуру функций и эвентов, поэтому подсказывает имена, типы аргументов и возвращаемых значений. Никаких any. 

// abi/erc20.ts — обычный JS-объект, помеченный `as const`
export const erc20Abi = [
  {
    type: 'function',
    name: 'balanceOf',
    stateMutability: 'view',
    inputs:  [{ name: 'account', type: 'address' }],
    outputs: [{ name: '',        type: 'uint256' }],
  },
  {
    type: 'function',
    name: 'transfer',
    stateMutability: 'nonpayable',
    inputs:  [
      { name: 'to',     type: 'address' },
      { name: 'amount', type: 'uint256' },
    ],
    outputs: [{ name: '', type: 'bool' }],
  },
  {
    type: 'event',
    name: 'Transfer',
    inputs: [
      { name: 'from',   type: 'address', indexed: true  },
      { name: 'to',     type: 'address', indexed: true  },
      { name: 'value',  type: 'uint256', indexed: false },
    ],
  },
] as const   // ← КРИТИЧНО: as const делает все строки литералами для TS

// Использование:
const USDC = '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48'

const balance: bigint = await publicClient.readContract({
  address: USDC,
  abi: erc20Abi,
  functionName: 'balanceOf',         // ← IDE подсказывает только реальные имена
  args: ['0x1234...abcd'],           // ← TS проверяет, что массив подходит сигнатуре
})

// balance — bigint, без BigNumber.toNumber() и прочих рудиментов ethers
Где взять as const. Если ABI приходит из artifacts/MyContract.json от Foundry/Hardhat — оборачивайте: import abi from '...json'; export const myAbi = abi.abi as const;. wagmi CLI делает это автоматически и кодогенерит готовые React-хуки (об этом — следующий урок).

3. writeContract и отправка транзакции

// Стандартный flow: simulate → write → wait

// 1. simulateContract — pre-flight check, ловит revert ДО подписи
const { request } = await publicClient.simulateContract({
  address: USDC,
  abi: erc20Abi,
  functionName: 'transfer',
  args: ['0xRecipient...', 100_000n],     // 0.1 USDC (6 decimals)
  account: '0xMyAddress...',
})

// 2. walletClient.writeContract — отправка с подписью кошелька
const hash = await walletClient.writeContract(request)
console.log('Tx hash:', hash)            // 0x...

// 3. publicClient.waitForTransactionReceipt — ждём подтверждения
const receipt = await publicClient.waitForTransactionReceipt({ hash })
console.log('Status:', receipt.status)   // 'success' | 'reverted'
console.log('Gas used:', receipt.gasUsed)

Паттерн simulate → write важен: simulate выполняет eth_call с тем же calldata и сразу видит revert-cause. Если без simulate сразу делать writeContract, пользователь может подписать заведомо неудачную транзакцию и потерять газ.

4. Декодирование событий

ERC-20 Transfer — каноничный пример. viem декодирует logs в строго типизированный объект: 

import { decodeEventLog, parseAbiItem } from 'viem'

// Через ABI всего контракта
const logs = await publicClient.getLogs({
  address: USDC,
  event: parseAbiItem('event Transfer(address indexed from, address indexed to, uint256 value)'),
  fromBlock: 18_000_000n,
  toBlock:   18_000_100n,
  args: { to: '0xMyAddress...' as `0x${string}` },   // фильтр по indexed-полю
})

for (const log of logs) {
  // log.args: { from: 0x..., to: 0x..., value: 1234567n } — типизировано
  console.log(`${log.args.from} → ${log.args.to}: ${log.args.value}`)
}

// Или подписаться на real-time через WebSocket transport:
const unwatch = publicClient.watchContractEvent({
  address: USDC,
  abi: erc20Abi,
  eventName: 'Transfer',
  onLogs: (logs) => {
    for (const l of logs) console.log('Transfer:', l.args)
  },
})

// Когда не нужно — отписаться
// unwatch()

5. Multicall — батч чтений за один RPC-вызов

Если нужно прочитать 20 балансов — это 20 RPC-запросов. Дорого по latency и по rate-limit на публичных нодах. Multicall3 — контракт, задеплоенный на всех major chains по детерминированному адресу 0xcA11bde05977b3631167028862bE2a173976CA11 — батчит вызовы на уровне EVM. 

const tokens = [
  '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48', // USDC
  '0xdAC17F958D2ee523a2206206994597C13D831ec7', // USDT
  '0x6B175474E89094C44Da98b954EedeAC495271d0F', // DAI
]

const calls = tokens.map(addr => ({
  address: addr,
  abi: erc20Abi,
  functionName: 'balanceOf',
  args: [myAddress],
}))

const results = await publicClient.multicall({ contracts: calls })
// results: [{ result: 1234n, status: 'success' }, { result: 5678n, ... }, ...]

results.forEach((r, i) => {
  if (r.status === 'success') {
    console.log(tokens[i], '→', r.result, 'wei')
  } else {
    console.warn(tokens[i], '→ failed:', r.error)
  }
})

// 1 HTTP-запрос вместо 3. На 50 чтениях экономия — секунды.

6. Газ и EIP-1559

viem полностью поддерживает EIP-1559 транзакции (с maxFeePerGas + maxPriorityFeePerGas). Для legacy chains, всё ещё использующих gasPrice, viem автоматически деградирует на правильный формат, основываясь на возможностях chain. 

// Узнать актуальные fee предложения (вычисляется из последних блоков)
const fees = await publicClient.estimateFeesPerGas()
console.log('maxFeePerGas:', fees.maxFeePerGas)             // bigint, в wei
console.log('maxPriorityFee:', fees.maxPriorityFeePerGas)   // bigint, в wei

// Оценка газа для конкретного вызова
const gas = await publicClient.estimateContractGas({
  address: USDC,
  abi: erc20Abi,
  functionName: 'transfer',
  args: ['0xRecipient...', 100_000n],
  account: myAddress,
})
console.log('Estimated gas:', gas)

// Итоговая стоимость:
const totalCostWei = gas * fees.maxFeePerGas
console.log('Max cost in ETH:', Number(totalCostWei) / 1e18)

// Кастомный приоритет (например, удвоенный, чтобы tx прошла быстрее):
const hash = await walletClient.writeContract({
  ...request,
  maxFeePerGas: fees.maxFeePerGas * 2n,
  maxPriorityFeePerGas: fees.maxPriorityFeePerGas * 2n,
})

7. parseUnits / formatUnits — никаких потерь точности

import { parseUnits, formatUnits, parseEther, formatEther } from 'viem'

// ETH: 18 decimals
const wei = parseEther('1.5')              // 1_500_000_000_000_000_000n
const eth = formatEther(wei)               // "1.5"

// USDC: 6 decimals
const usdc = parseUnits('100.5', 6)        // 100_500_000n
const back = formatUnits(usdc, 6)          // "100.5"

// Никогда: parseFloat / Number(bigint).toString() — теряет точность для больших сумм.
// При работе с ценами/балансами всегда BigInt + parseUnits/formatUnits.

8. Тестирование с anvil-fork и viem

Локальный fork mainnet через Anvil + createTestClient позволяет делать снапшоты, перематывать блок, выставлять баланс — для интеграционных тестов это золотой стандарт. 

import { createTestClient, http } from 'viem'
import { anvil } from 'viem/chains'

const testClient = createTestClient({
  chain: anvil,
  mode: 'anvil',
  transport: http('http://127.0.0.1:8545'),
})

// Поставить балансу WHALE_ADDR 1000 ETH
await testClient.setBalance({
  address: '0x...whale...',
  value: 1000_000000000000000000n,
})

// Снапшот state
const snap = await testClient.snapshot()

// ...сделать какие-то транзакции...

// Откатить state
await testClient.revert({ id: snap })

// Перемотать время для тестов времени-зависимых протоколов:
await testClient.increaseTime({ seconds: 86400 })       // +1 день
await testClient.mine({ blocks: 1 })                    // майним один блок

# Шаг 2: src/read.ts
import { createPublicClient, http, formatUnits } from 'viem'
import { mainnet } from 'viem/chains'

const erc20Abi = [
  {
    type: 'function',
    name: 'totalSupply',
    stateMutability: 'view',
    inputs: [],
    outputs: [{ type: 'uint256' }],
  },
  {
    type: 'function',
    name: 'symbol',
    stateMutability: 'view',
    inputs: [],
    outputs: [{ type: 'string' }],
  },
] as const

const client = createPublicClient({
  chain: mainnet,
  transport: http('https://eth.llamarpc.com'),
})

const USDC = '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48' as const

const [supply, symbol] = await Promise.all([
  client.readContract({ address: USDC, abi: erc20Abi, functionName: 'totalSupply' }),
  client.readContract({ address: USDC, abi: erc20Abi, functionName: 'symbol' }),
])

console.log(`Total ${symbol} supply:`, formatUnits(supply, 6))
# Ожидаемый вывод: ≈ 35_000_000_000 USDC (точное число зависит от блока)

npx tsx src/read.ts

Задача 2 — Отправить токены через simulate → write → wait

В этой задаче мы запускаем Anvil-fork mainnet, прикидываемся одним из whale-аккаунтов через impersonate и переводим USDC. Это даёт полностью реалистичный тест без потери настоящего ETH. 

# Терминал 1: запустить fork
anvil --fork-url https://eth.llamarpc.com --auto-impersonate

# Терминал 2: src/transfer.ts
import { createPublicClient, createWalletClient, http, parseUnits } from 'viem'
import { foundry } from 'viem/chains'
import { erc20Abi } from './abi/erc20'   // тот же ABI с transfer

const USDC = '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48' as const
const WHALE = '0x55FE002aefF02F77364de339a1292923A15844B8' as const  // Circle hot wallet
const RECIPIENT = '0x0000000000000000000000000000000000000001' as const

const publicClient = createPublicClient({
  chain: foundry,
  transport: http('http://127.0.0.1:8545'),
})

const walletClient = createWalletClient({
  chain: foundry,
  account: WHALE,                          // на forked chain с impersonate — работает без приватного ключа
  transport: http('http://127.0.0.1:8545'),
})

// 1. Simulate
const { request } = await publicClient.simulateContract({
  account: WHALE,
  address: USDC,
  abi: erc20Abi,
  functionName: 'transfer',
  args: [RECIPIENT, parseUnits('100', 6)],
})

// 2. Write
const hash = await walletClient.writeContract(request)
console.log('Tx hash:', hash)

// 3. Wait
const receipt = await publicClient.waitForTransactionReceipt({ hash })
console.log('Status:', receipt.status, '| gas:', receipt.gasUsed)

# Запуск:
npx tsx src/transfer.ts

Задача 3 — Получить последние 100 Transfer-логов USDC

// src/logs.ts
import { createPublicClient, http, parseAbiItem, formatUnits } from 'viem'
import { mainnet } from 'viem/chains'

const client = createPublicClient({
  chain: mainnet,
  transport: http('https://eth.llamarpc.com'),
})

const USDC = '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48' as const
const transferEvent = parseAbiItem(
  'event Transfer(address indexed from, address indexed to, uint256 value)'
)

const latest = await client.getBlockNumber()
const logs = await client.getLogs({
  address: USDC,
  event: transferEvent,
  fromBlock: latest - 100n,
  toBlock: latest,
})

for (const log of logs.slice(-10)) {
  console.log(
    `${log.args.from?.slice(0,6)}… → ${log.args.to?.slice(0,6)}…`,
    formatUnits(log.args.value ?? 0n, 6),
    'USDC',
  )
}

Задача 4 — Multicall: 5 балансов за один запрос

// src/multicall.ts
import { createPublicClient, http, formatUnits } from 'viem'
import { mainnet } from 'viem/chains'
import { erc20Abi } from './abi/erc20'

const client = createPublicClient({
  chain: mainnet,
  transport: http('https://eth.llamarpc.com'),
  batch: { multicall: true },     // включить автоматический multicall для readContract
})

const HOLDER = '0x28C6c06298d514Db089934071355E5743bf21d60' as const  // Binance 14
const TOKENS = [
  '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48', // USDC
  '0xdAC17F958D2ee523a2206206994597C13D831ec7', // USDT
  '0x6B175474E89094C44Da98b954EedeAC495271d0F', // DAI
  '0x2260FAC5E5542a773Aa44fBCfeDf7C193bc2C599', // WBTC
  '0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2', // WETH
] as const

// Способ 1: явный multicall
const results = await client.multicall({
  contracts: TOKENS.map(addr => ({
    address: addr,
    abi: erc20Abi,
    functionName: 'balanceOf',
    args: [HOLDER],
  })),
})

results.forEach((r, i) => {
  if (r.status === 'success')
    console.log(TOKENS[i].slice(0, 8), '→', r.result)
})

// Способ 2: с batch: { multicall: true } можно использовать параллельные readContract,
// и viem сам соберёт их в один multicall
const balances = await Promise.all(
  TOKENS.map(addr => client.readContract({
    address: addr,
    abi: erc20Abi,
    functionName: 'balanceOf',
    args: [HOLDER],
  }))
)
console.log(balances)

# Запуск:
npx tsx src/multicall.ts
