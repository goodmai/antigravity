AAVE: Flash Loans — атомарные займы без залога

Flash loan — это заём, который должен быть возвращён в той же транзакции, в которой выдан. Если к концу транзакции долг не погашен с процентами, вся транзакция ревертится, как будто ничего не произошло. Это означает, что протокол никогда не рискует своими средствами: либо всё завершилось успешно и процент получен, либо состояние блокчейна откатилось к началу.

Именно эта атомарная гарантия позволяет одалживать миллионы долларов без какого-либо залога, без KYC и без кредитного рейтинга. Единственное условие — возможность вернуть деньги до закрытия транзакции. AAVE сделал flash loans частью протокола с V1, а в V3 — основным инструментом для сложных DeFi-операций.

Что вы получите. После этого урока вы сможете: объяснить атомарную механику flash loan; различить flashLoan() и flashLoanSimple(); написать контракт-получатель со всеми необходимыми проверками безопасности; рассчитать стоимость займа через FLASHLOAN_PREMIUM_TOTAL; перечислить реальные use cases — арбитраж, swap залога, само-ликвидацию и рефинансирование.

1. Что такое flash loan

Классический кредит работает так: заёмщик предоставляет залог, получает ликвидность, использует её, позже возвращает основную сумму с процентами. Риск невозврата управляется через overcollateralization (залог больше займа).

Flash loan переворачивает эту логику: атомарность транзакции EVM выступает залогом. Если код в транзакции не сможет вернуть средства, EVM откатит все изменения состояния — у протокола просто не «отберут» ничего, потому что взятие и возврат происходят в одном неделимом атоме исполнения.

1.1 Жизненный цикл одной flash loan транзакции

1. Ваш контракт вызывает  Pool.flashLoan(...)
          │
          │  Pool переводит запрошенные токены  → вашему контракту
          │
          ▼
2. Pool.executeOperation() вызывается на вашем контракте (callback)
          │
          │  Здесь вы делаете всё что хотите:
          │    - арбитраж на DEX
          │    - ликвидация позиции
          │    - замена залога
          │
          ▼
3. Ваш контракт делает approve(Pool, amount + fee)
4. Pool.transferFrom(вашего_контракта, amount + fee)   ← возврат
          │
          │  Если approve/transferFrom упал → вся транзакция revert
          ▼
5. Транзакция успешно включена в блок
   Ваша прибыль = то, что осталось на балансе контракта

1.2 Почему это возможно без залога

Весь риск исчезает благодаря атомарности: состояние EVM является консистентным в любой момент после завершения транзакции, но в ходе исполнения ничто не «зафиксировано» до самого конца. Реверт — это как будто ничего не было: Pool не потеряет токены, потому что транзакция, не вернувшая деньги, просто не существует в блокчейне.

2. AAVE V3: два интерфейса flash loan

AAVE V3 предоставляет два метода на контракте Pool. Разница — в количестве токенов за один вызов и в механизме колбэка:

МетодТокеныCallbackКогда использовать
flashLoan() Несколько активов одновременно executeOperation(address[], uint256[], uint256[], address, bytes) Сложные операции: swap залога, одновременный арбитраж нескольких пар
flashLoanSimple() Один актив executeOperation(address, uint256, uint256, address, bytes) Простые случаи: однотокенный арбитраж, само-ликвидация одной позиции

2.1 Интерфейс IFlashLoanReceiver

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

// Из репозитория aave-v3-core
interface IFlashLoanReceiver {
    /**
     * @dev Вызывается Pool'ом после перевода средств.
     * @param assets       Адреса токенов (для flashLoan)
     * @param amounts      Суммы займа по каждому токену
     * @param premiums     Стоимость займа (fee) по каждому токену
     * @param initiator    Адрес, инициировавший flashLoan (важно для security!)
     * @param params       Произвольные данные, которые вы передали в flashLoan()
     * @return             Должен вернуть true, иначе Pool ревертится
     */
    function executeOperation(
        address[] calldata assets,
        uint256[] calldata amounts,
        uint256[] calldata premiums,
        address initiator,
        bytes calldata params
    ) external returns (bool);
}

interface IFlashLoanSimpleReceiver {
    function executeOperation(
        address asset,
        uint256 amount,
        uint256 premium,
        address initiator,
        bytes calldata params
    ) external returns (bool);
}

2.2 Сигнатура flashLoan в контракте Pool

interface IPool {
    /**
     * @param receiverAddress  Контракт-получатель (должен имплементировать IFlashLoanReceiver)
     * @param assets           Массив адресов токенов
     * @param amounts          Массив сумм займа
     * @param interestRateModes  0 = без долга (flash), 1 = stable, 2 = variable
     * @param onBehalfOf       Адрес для открытия долга (только если interestRateMode != 0)
     * @param params           Произвольные данные для executeOperation
     * @param referralCode     Код реферала (0 для прямых вызовов)
     */
    function flashLoan(
        address receiverAddress,
        address[] calldata assets,
        uint256[] calldata amounts,
        uint256[] calldata interestRateModes,
        address onBehalfOf,
        bytes calldata params,
        uint16 referralCode
    ) external;

    function flashLoanSimple(
        address receiverAddress,
        address asset,
        uint256 amount,
        bytes calldata params,
        uint16 referralCode
    ) external;
}
interestRateModes = 0 — это именно flash loan: заём без залога, обязан быть погашен в той же транзакции. Значения 1 и 2 превращают flash loan в обычный кредит (с оставлением долга), что требует достаточного залога в AAVE у onBehalfOf.

3. Полный пример: арбитражный flash loan контракт

Классический сценарий: цена USDC/ETH на DEX A дешевле, чем на DEX B. Берём USDC в долг, покупаем ETH на DEX A, продаём ETH на DEX B, возвращаем USDC + fee, прибыль остаётся в контракте. 

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import {IERC20} from "@openzeppelin/contracts/token/ERC20/IERC20.sol";
import {SafeERC20} from "@openzeppelin/contracts/token/ERC20/utils/SafeERC20.sol";
import {Ownable} from "@openzeppelin/contracts/access/Ownable.sol";

// ─── AAVE V3 интерфейсы ──────────────────────────────────────────────────────

interface IPool {
    function flashLoanSimple(
        address receiverAddress,
        address asset,
        uint256 amount,
        bytes calldata params,
        uint16 referralCode
    ) external;
}

interface IFlashLoanSimpleReceiver {
    function executeOperation(
        address asset,
        uint256 amount,
        uint256 premium,
        address initiator,
        bytes calldata params
    ) external returns (bool);
}

// ─── Упрощённые интерфейсы DEX (Uniswap V2-совместимые) ─────────────────────

interface IUniswapV2Router {
    function swapExactTokensForTokens(
        uint256 amountIn,
        uint256 amountOutMin,
        address[] calldata path,
        address to,
        uint256 deadline
    ) external returns (uint256[] memory amounts);
}

// ─── Арбитражный контракт ────────────────────────────────────────────────────

contract FlashLoanArbitrage is IFlashLoanSimpleReceiver, Ownable {
    using SafeERC20 for IERC20;

    // AAVE V3 Pool на Ethereum mainnet
    IPool public constant POOL =
        IPool(0x87870Bca3F3fD6335C3F4ce8392D69350B4fA4E2);

    IUniswapV2Router public immutable dexA; // дешевле покупать ETH
    IUniswapV2Router public immutable dexB; // дороже продавать ETH

    address public constant USDC = 0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48;
    address public constant WETH = 0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2;

    // ── Events ────────────────────────────────────────────────────────────────
    event ArbitrageExecuted(
        uint256 borrowed,
        uint256 fee,
        uint256 profit
    );

    constructor(
        address _dexA,
        address _dexB,
        address initialOwner
    ) Ownable(initialOwner) {
        dexA = IUniswapV2Router(_dexA);
        dexB = IUniswapV2Router(_dexB);
    }

    // ── Шаг 1: Инициировать арбитраж ─────────────────────────────────────────
    /**
     * @dev Вызывается owner'ом для старта арбитражной флэш-транзакции.
     * @param usdcAmount  Сумма USDC для займа (с 6 десятичными знаками)
     * @param minProfit   Минимальная ожидаемая прибыль в USDC (защита от slippage)
     */
    function executeArbitrage(
        uint256 usdcAmount,
        uint256 minProfit
    ) external onlyOwner {
        // Кодируем параметры для передачи в executeOperation
        bytes memory params = abi.encode(minProfit);

        POOL.flashLoanSimple(
            address(this), // receiver = этот контракт
            USDC,          // берём USDC
            usdcAmount,    // сколько
            params,        // наши параметры
            0              // referralCode
        );
    }

    // ── Шаг 2: Callback от AAVE Pool ─────────────────────────────────────────
    /**
     * @dev Вызывается Pool ПОСЛЕ перевода usdcAmount на этот контракт.
     *      Мы должны вернуть amount + premium до завершения этой функции.
     */
    function executeOperation(
        address asset,
        uint256 amount,
        uint256 premium,
        address initiator,
        bytes calldata params
    ) external override returns (bool) {
        // ── Проверки безопасности ──────────────────────────────────────────────
        // 1) Только AAVE Pool может вызывать этот коллбэк
        require(msg.sender == address(POOL), "Caller must be AAVE Pool");
        // 2) Flash loan должен быть инициирован только этим контрактом
        require(initiator == address(this), "Initiator must be this contract");
        // 3) Только USDC принимаем
        require(asset == USDC, "Only USDC flash loans");

        uint256 minProfit = abi.decode(params, (uint256));
        uint256 totalDebt = amount + premium; // сколько нужно вернуть

        // ── Шаг А: покупаем WETH на DEX A за USDC ────────────────────────────
        IERC20(USDC).safeApprove(address(dexA), amount);

        address[] memory pathAtoB = new address[](2);
        pathAtoB[0] = USDC;
        pathAtoB[1] = WETH;

        uint256[] memory amountsOut = dexA.swapExactTokensForTokens(
            amount,
            0,                    // amountOutMin — в проде ставьте оракул-цену!
            pathAtoB,
            address(this),
            block.timestamp + 60
        );
        uint256 wethReceived = amountsOut[amountsOut.length - 1];

        // ── Шаг Б: продаём WETH на DEX B за USDC ─────────────────────────────
        IERC20(WETH).safeApprove(address(dexB), wethReceived);

        address[] memory pathBtoA = new address[](2);
        pathBtoA[0] = WETH;
        pathBtoA[1] = USDC;

        uint256[] memory amountsBack = dexB.swapExactTokensForTokens(
            wethReceived,
            totalDebt,            // минимум — хотя бы вернуть долг
            pathBtoA,
            address(this),
            block.timestamp + 60
        );
        uint256 usdcReceived = amountsBack[amountsBack.length - 1];

        // ── Шаг В: проверяем прибыльность ────────────────────────────────────
        require(usdcReceived >= totalDebt + minProfit, "Insufficient profit");
        uint256 profit = usdcReceived - totalDebt;

        // ── Шаг Г: даём Pool право забрать долг ───────────────────────────────
        // ВАЖНО: approve именно на POOL, а не на что-то другое
        IERC20(USDC).safeApprove(address(POOL), totalDebt);

        emit ArbitrageExecuted(amount, premium, profit);

        // Возвращаем true — сигнал Pool, что всё хорошо
        return true;
        // Сразу после return Pool делает transferFrom(this, totalDebt)
    }

    // ── Утилиты ───────────────────────────────────────────────────────────────

    /// @dev Вывод прибыли владельцу
    function withdraw(address token) external onlyOwner {
        uint256 bal = IERC20(token).balanceOf(address(this));
        IERC20(token).safeTransfer(owner(), bal);
    }

    /// @dev Аварийный вывод ETH (если DEX вернул native ETH)
    function withdrawETH() external onlyOwner {
        payable(owner()).transfer(address(this).balance);
    }

    receive() external payable {}
}
Важно для продакшна. В примере выше amountOutMin = 0 для простоты изложения. В реальном коде всегда рассчитывайте минимальный выход через оракул (Chainlink) или проводите simulation через eth_call перед отправкой транзакции. Без этого MEV-боты могут провести sandwich-атаку и обнулить прибыль.

4. Структура комиссий AAVE V3

AAVE V3 берёт комиссию 0.05% от суммы flash loan. Это значение хранится в константе FLASHLOAN_PREMIUM_TOTAL (= 5 basis points = 0.0005). Комиссия делится на две части:

ПараметрЗначениеКто получает
FLASHLOAN_PREMIUM_TOTAL 5 bps = 0.05% Суммарная комиссия (LP + протокол)
FLASHLOAN_PREMIUM_TO_PROTOCOL 4 bps (80% от total) Treasury протокола AAVE
LP-доля 1 bps (20% от total) Поставщики ликвидности aToken

4.1 Расчёт комиссии

// Формула, которую использует Pool:
// premium = amount * FLASHLOAN_PREMIUM_TOTAL / 10_000
//
// Пример: займём 1 000 000 USDC (1e12 с 6 decimals)
uint256 amount  = 1_000_000 * 1e6;   // 1M USDC
uint256 premium = amount * 5 / 10_000; // = 500 USDC (0.05%)
uint256 totalDebt = amount + premium;  // = 1_000_500 USDC

// Значит, для прибыли арбитраж должен принести > 500 USDC
// (+ ещё учесть gas ~200-400k gas * gasPrice)

Для сравнения: Uniswap V3 flash loan берёт 0.3% (или 0.05% в пулах с низкой комиссией). AAVE V3 значительно дешевле, что делает его предпочтительным для операций с маржинальной прибылью.

5. Use cases flash loans

5.1 Арбитраж

Самый очевидный сценарий. Ценовые расхождения между DEX'ами существуют миллисекунды — flash loan позволяет использовать их без собственного капитала. На практике в 2024–2025 году большинство арбитражных возможностей захватываются MEV-ботами через private mempools (Flashbots, MEV Blocker), а не публичными транзакциями.

5.2 Своп залога (Collateral Swap)

Представьте: у вас в AAVE открыта позиция «ETH залог → USDC долг», но вы хотите поменять залог на WBTC. Без flash loan — это несколько транзакций и огромный риск ликвидации в промежутке. С flash loan: 

1. Flash loan USDC (равный вашему долгу)
2. Погасить USDC долг в AAVE → разблокировать ETH залог
3. Вывести ETH из AAVE
4. Продать ETH → WBTC на DEX
5. Внести WBTC в AAVE как новый залог
6. Взять USDC в долг снова
7. Вернуть flash loan (USDC + fee)
— всё в одной транзакции, ноль риска ликвидации

5.3 Само-ликвидация (Self-Liquidation)

Когда позиция приближается к порогу ликвидации (health factor → 1.0), вы можете самостоятельно ликвидировать себя через flash loan — и получить liquidation bonus себе, а не стороннему ликвидатору. Экономия обычно 5–10% от залога.

5.4 Рефинансирование долга (Debt Refinancing)

Переместить позицию из Compound в AAVE с более низкой ставкой: 

1. Flash loan USDC (ваш долг в Compound)
2. Погасить долг в Compound → разблокировать залог
3. Перевести залог в AAVE
4. Взять USDC в долг в AAVE
5. Вернуть flash loan
— позиция переехала без промежуточного капитала

5.5 Ликвидация чужих позиций

Flash loan финансирует погашение долга ликвидируемой позиции, ликвидатор получает залог с бонусом (5–15% в AAVE), избыток оставляет себе. Это формирует конкурентный рынок ликвидаторов — в итоге позиции ликвидируются быстрее, протокол безопаснее.

5.6 DeFi-агрегаторы: та же атомарность, но для маршрутизации

Та же атомарная гарантия EVM, что делает flash loan безопасным, лежит в основе DeFi-агрегаторов ликвидности (1inch, 0x на EVM; Jupiter на Solana). Агрегатор — это высокочастотная «поисковая система» по разрозненным пулам DEX: он находит оптимальный маршрут обмена и разбивает ордер на части для снижения проскальзывания. Весь каскад обменов исполняется в одной транзакции — если на любом шаге ликвидности не хватило, вся операция делает revert и пользователь не теряет средства. В традиционной банковской маршрутизации это технически недостижимо.

Компонент EVM (1inch, 0x) Solana (Jupiter)
Вычисление маршрута Off-chain Pathfinder анализирует mempool/RPC, перебирает пути Ядро Metis: кэшированные on-chain чтения, без сетевых вызовов
Исполнение API отдаёт готовый байт-код tx → подпись → атомарное исполнение Пакетная обработка с учётом сверхбыстрой смены состояния аккаунтов
Специфический риск MEV (фронтраннинг, сэндвич-атаки), волатильность газа Сложная модель аккаунтов, отказы при смене ликвидности до финализации
Связь с разделом 6.4. Агрегатор off-chain считает котировку, но on-chain она исполняется в публичном mempool — это та же поверхность MEV/sandwich, что и при манипуляции ценой через flash loan. Поэтому агрегаторы выставляют minReturn/slippage-bound: это on-chain инвариант, дающий ту же «всё-или-revert» защиту.

6. Безопасность flash loan контракта

6.1 Проверка вызывающего (msg.sender)

Функция executeOperation объявлена как external и может вызвать кто угодно. Без проверки злоумышленник вызовет её напрямую, передав ложные параметры. 

// ❌ НЕБЕЗОПАСНО — executeOperation без проверок
function executeOperation(...) external returns (bool) {
    // ... используем amount ...
    IERC20(asset).approve(address(POOL), amount + premium);
    return true;
}

// ✅ БЕЗОПАСНО
function executeOperation(...) external returns (bool) {
    require(msg.sender == address(POOL),    "Only AAVE Pool");
    require(initiator  == address(this),    "Only self-initiated");
    // ... логика ...
    return true;
}

6.2 Reentrancy

Flash loan callback — это входная точка, которую Pool вызывает изнутри вашей же транзакции. Если ваш контракт взаимодействует с ненадёжными внешними контрактами, используйте nonReentrant из OpenZeppelin или паттерн checks-effects-interactions. 

import {ReentrancyGuard} from "@openzeppelin/contracts/utils/ReentrancyGuard.sol";

contract SafeFlashLoan is IFlashLoanSimpleReceiver, ReentrancyGuard, Ownable {
    function executeOperation(
        address asset,
        uint256 amount,
        uint256 premium,
        address initiator,
        bytes calldata params
    ) external nonReentrant returns (bool) {
        require(msg.sender == address(POOL), "Only AAVE Pool");
        require(initiator == address(this),  "Only self-initiated");
        // ...
        return true;
    }
}

6.3 Управление approve

После каждой flash loan транзакции у Pool остаётся неиспользованный approve? Нет — Pool вызывает transferFrom сразу в той же транзакции, что забирает ровно amount + premium. Но если вы делаете approve(pool, type(uint256).max) — это избыточно и опасно: Pool сможет вытащить любую сумму позже. Правильная практика: 

// Одобряем ровно столько, сколько нужно вернуть
IERC20(asset).safeApprove(address(POOL), 0);           // сбрасываем старое
IERC20(asset).safeApprove(address(POOL), totalDebt);   // устанавливаем точное

6.4 Манипуляция ценой через flash loan

Flash loan сами по себе безопасны, но могут использоваться для манипуляции ценовыми оракулами, основанными на spot price (мгновенной цене) DEX. Атакующий берёт огромный flash loan, двигает цену в пуле, эксплуатирует протокол с ложной ценой, возвращает деньги. Решение — использовать TWAP-оракулы (Uniswap V3) или Chainlink Price Feeds, а не spot price.

7. Паттерн executeOperation: полный шаблон

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import {IERC20}            from "@openzeppelin/contracts/token/ERC20/IERC20.sol";
import {SafeERC20}         from "@openzeppelin/contracts/token/ERC20/utils/SafeERC20.sol";
import {ReentrancyGuard}   from "@openzeppelin/contracts/utils/ReentrancyGuard.sol";
import {Ownable}           from "@openzeppelin/contracts/access/Ownable.sol";

interface IPool {
    function flashLoan(
        address receiverAddress,
        address[] calldata assets,
        uint256[] calldata amounts,
        uint256[] calldata interestRateModes,
        address onBehalfOf,
        bytes calldata params,
        uint16 referralCode
    ) external;
}

interface IFlashLoanReceiver {
    function executeOperation(
        address[] calldata assets,
        uint256[] calldata amounts,
        uint256[] calldata premiums,
        address initiator,
        bytes calldata params
    ) external returns (bool);
}

/// @title  FlashLoanBase — базовый шаблон для flash loan контрактов на AAVE V3
/// @notice Наследуйте этот контракт и переопределите _executeLogic()
abstract contract FlashLoanBase is IFlashLoanReceiver, ReentrancyGuard, Ownable {
    using SafeERC20 for IERC20;

    IPool public immutable POOL;

    constructor(address pool, address initialOwner) Ownable(initialOwner) {
        POOL = IPool(pool);
    }

    // ── Публичная точка входа ─────────────────────────────────────────────────

    function initiateFlashLoan(
        address[] calldata assets,
        uint256[] calldata amounts,
        bytes calldata params
    ) external onlyOwner {
        uint256[] memory modes = new uint256[](assets.length);
        // modes[i] = 0 → flash loan без долга

        POOL.flashLoan(
            address(this),
            assets,
            amounts,
            modes,
            address(this),
            params,
            0
        );
    }

    // ── Callback от AAVE ──────────────────────────────────────────────────────

    function executeOperation(
        address[] calldata assets,
        uint256[] calldata amounts,
        uint256[] calldata premiums,
        address initiator,
        bytes calldata params
    ) external override nonReentrant returns (bool) {
        // ── Проверки безопасности ──────────────────────────────────────────
        require(msg.sender == address(POOL), "Caller must be AAVE Pool");
        require(initiator == address(this),  "Initiator must be this contract");

        // ── Ваша бизнес-логика ─────────────────────────────────────────────
        _executeLogic(assets, amounts, premiums, params);

        // ── Одобрить возврат долга ────────────────────────────────────────
        for (uint256 i = 0; i < assets.length; i++) {
            uint256 totalDebt = amounts[i] + premiums[i];
            IERC20(assets[i]).safeApprove(address(POOL), 0);
            IERC20(assets[i]).safeApprove(address(POOL), totalDebt);
        }

        return true;
    }

    // ── Абстрактная логика (переопределите в наследнике) ──────────────────────

    function _executeLogic(
        address[] calldata assets,
        uint256[] calldata amounts,
        uint256[] calldata premiums,
        bytes calldata params
    ) internal virtual;

    // ── Утилиты ───────────────────────────────────────────────────────────────

    function rescueToken(address token) external onlyOwner {
        uint256 bal = IERC20(token).balanceOf(address(this));
        IERC20(token).safeTransfer(owner(), bal);
    }
}
