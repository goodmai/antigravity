wagmi — React-хуки поверх viem

→ продолжение Lesson 11 — viem. Тот же type-safe ABI, но обёрнут в идиоматичный React.

wagmi («waggy») — библиотека React-хуков для EVM-цепей, построенная на трёх китах: viem (типизированный JSON-RPC), @tanstack/react-query (кеширование, refetch, stale-while-revalidate), и единый WagmiConfig. Каждое состояние блокчейна — это запрос; каждый запрос автоматически кешируется, инвалидируется на новом блоке и шарится между компонентами. Результат — React-приложение, которое «понимает» chain так же, как обычные хуки понимают useQuery.

Что вы получите. После урока вы умеете: настроить WagmiProvider с несколькими chains; использовать useReadContract / useReadContracts для типизированного чтения; useWriteContract + simulate-хук для безопасной отправки tx; useWatchContractEvent для real-time обновлений; кодогенерировать хуки через @wagmi/cli.

1. Установка и WagmiProvider

# Установка
npm create vite@latest dapp -- --template react-ts
cd dapp
npm i wagmi viem @tanstack/react-query
npm i @web3modal/wagmi   # (опционально) готовый UI для подключения кошельков
// src/wagmi.ts
import { createConfig, http } from 'wagmi'
import { mainnet, sepolia, base } from 'wagmi/chains'
import { injected, walletConnect } from 'wagmi/connectors'

export const config = createConfig({
  chains: [mainnet, sepolia, base],
  connectors: [
    injected(),                              // MetaMask, Rabby и любой EIP-1193 wallet
    walletConnect({ projectId: 'YOUR_PROJECT_ID' }),
  ],
  transports: {
    [mainnet.id]: http('https://eth.llamarpc.com'),
    [sepolia.id]: http('https://rpc.sepolia.org'),
    [base.id]:    http('https://mainnet.base.org'),
  },
  ssr: false,                                // выставите true для Next.js
})

declare module 'wagmi' {
  interface Register {
    config: typeof config
  }
}
// src/main.tsx
import { WagmiProvider } from 'wagmi'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { config } from './wagmi'
import { App } from './App'

const queryClient = new QueryClient()

ReactDOM.createRoot(document.getElementById('root')!).render(
  <WagmiProvider config={config}>
    <QueryClientProvider client={queryClient}>
      <App />
    </QueryClientProvider>
  </WagmiProvider>,
)
Почему два провайдера. wagmi хранит состояние коннектора (WagmiProvider) и кеш данных контракта (QueryClientProvider). Это разные ответственности и разные жизненные циклы. Кеш чтения должен переживать переключение кошелька; коннектор должен переживать перезагрузку страницы (через localStorage).

2. useAccount, useConnect, useDisconnect

// src/ConnectButton.tsx
import { useAccount, useConnect, useDisconnect } from 'wagmi'

export function ConnectButton() {
  const { address, isConnected, chain } = useAccount()
  const { connectors, connect, isPending } = useConnect()
  const { disconnect } = useDisconnect()

  if (isConnected) {
    return (
      <div>
        <span>{address?.slice(0, 6)}…{address?.slice(-4)}</span>
        <span> · {chain?.name}</span>
        <button onClick={() => disconnect()}>Disconnect</button>
      </div>
    )
  }

  return (
    <div>
      {connectors.map(c => (
        <button
          key={c.id}
          onClick={() => connect({ connector: c })}
          disabled={isPending}
        >
          Connect {c.name}
        </button>
      ))}
    </div>
  )
}

3. useReadContract — типизированное чтение

// src/UsdcBalance.tsx
import { useAccount, useReadContract } from 'wagmi'
import { formatUnits } from 'viem'

const erc20Abi = [
  {
    type: 'function', name: 'balanceOf', stateMutability: 'view',
    inputs:  [{ name: 'account', type: 'address' }],
    outputs: [{ name: '',        type: 'uint256' }],
  },
  {
    type: 'function', name: 'decimals', stateMutability: 'view',
    inputs: [], outputs: [{ type: 'uint8' }],
  },
] as const

const USDC = '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48' as const

export function UsdcBalance() {
  const { address } = useAccount()

  const { data, isLoading, error, refetch } = useReadContract({
    address: USDC,
    abi: erc20Abi,
    functionName: 'balanceOf',
    args: address ? [address] : undefined,
    query: { enabled: !!address },          // не вызывать, пока address пустой
  })

  if (!address)     return <p>Подключите кошелёк</p>
  if (isLoading)    return <p>Загрузка балансов…</p>
  if (error)        return <p>Ошибка: {error.shortMessage}</p>

  return (
    <div>
      <p>Баланс USDC: {formatUnits(data ?? 0n, 6)}</p>
      <button onClick={() => refetch()}>Обновить</button>
    </div>
  )
}

Под капотом wagmi кеширует результат под ключом ['readContract', { address, functionName, args, chainId }]. Любой другой компонент с тем же запросом мгновенно получит закешированное значение — без второго RPC-вызова.

4. useReadContracts — несколько чтений сразу

import { useReadContracts } from 'wagmi'

export function TokenList({ address, tokens }: { address: \`0x\${string}\`, tokens: \`0x\${string}\`[] }) {
  const { data, isLoading } = useReadContracts({
    contracts: tokens.flatMap(token => [
      {
        address: token,
        abi: erc20Abi,
        functionName: 'balanceOf',
        args: [address],
      },
      {
        address: token,
        abi: erc20Abi,
        functionName: 'symbol',
      },
    ]),
    query: { enabled: !!address },
  })

  if (isLoading || !data) return <p>Загрузка…</p>

  // data[0] — balance USDC, data[1] — symbol USDC, data[2] — balance USDT…
  return (
    <ul>
      {tokens.map((t, i) => (
        <li key={t}>
          {data[i * 2 + 1].result as string}: {(data[i * 2].result as bigint).toString()}
        </li>
      ))}
    </ul>
  )
}

// useReadContracts автоматически батчит в один Multicall3-запрос.

5. useSimulateContract + useWriteContract — write-flow

// src/Transfer.tsx
import { useAccount, useSimulateContract, useWriteContract, useWaitForTransactionReceipt } from 'wagmi'
import { parseUnits } from 'viem'

export function Transfer() {
  const { address } = useAccount()

  // 1. Simulate — pre-flight check, проверяет revert ДО подписи
  const { data: simulation, error: simError } = useSimulateContract({
    address: USDC,
    abi: erc20Abi,
    functionName: 'transfer',
    args: ['0xRecipient...', parseUnits('1', 6)],     // 1 USDC
    query: { enabled: !!address },
  })

  // 2. Write — выполняется при клике
  const { writeContract, data: hash, isPending: isSigning, error: writeError } = useWriteContract()

  // 3. Wait — дожидаемся подтверждения
  const { isLoading: isMining, isSuccess } = useWaitForTransactionReceipt({ hash })

  return (
    <div>
      <button
        disabled={!simulation || isSigning || isMining}
        onClick={() => writeContract(simulation!.request)}
      >
        {isSigning ? 'Подпишите в кошельке…' : isMining ? 'Майнинг…' : 'Send 1 USDC'}
      </button>

      {simError && <p>Симуляция упала: {simError.shortMessage}</p>}
      {writeError && <p>Ошибка подписи: {writeError.shortMessage}</p>}
      {isSuccess && <p>Транзакция в блоке: {hash}</p>}
    </div>
  )
}
Зачем три хука вместо одного. Каждый этап имеет своё состояние: simulate — «знаем ли мы заранее, что tx пройдёт»; write — «подписывает ли пользователь сейчас»; wait — «есть ли уже receipt». UI рисует каждое состояние своим текстом и dis/enabled — это и есть «правильный» web3 UX.

6. useWatchContractEvent — real-time

import { useWatchContractEvent } from 'wagmi'

export function TransferToast() {
  const { address } = useAccount()

  useWatchContractEvent({
    address: USDC,
    abi: erc20Abi,
    eventName: 'Transfer',
    args: address ? { to: address } : undefined,    // фильтр по indexed-полю
    onLogs(logs) {
      for (const log of logs) {
        toast.success(\`Received \${formatUnits(log.args.value!, 6)} USDC\`)
      }
    },
  })

  return null
}

Хук автоматически отписывается при unmount компонента. Под HTTP-transport делается long-polling раз в block-time; под WebSocket — настоящая subscribe.

7. wagmi CLI — кодогенерация типизированных хуков

Вместо того, чтобы вручную писать ABI и useReadContract({ abi, functionName: 'balanceOf' }), @wagmi/cli кодогенерирует именованные хуки типа useReadErc20BalanceOf с фиксированным ABI. Это убирает повторение и даёт лучший IntelliSense. 

# Установка
npm i -D @wagmi/cli

# wagmi.config.ts
import { defineConfig } from '@wagmi/cli'
import { foundry, react } from '@wagmi/cli/plugins'

export default defineConfig({
  out: 'src/generated.ts',
  contracts: [
    {
      name: 'usdc',
      address: '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48',
      abi: [/* … erc20 ABI … */] as const,
    },
  ],
  plugins: [
    foundry({ project: '../contracts' }),  // авто-импорт всех контрактов из Foundry-проекта
    react(),                                // кодогенерация React-хуков
  ],
})

# Запуск
npx wagmi generate

8. Многоцепочечная логика — useSwitchChain

import { useAccount, useSwitchChain, useChainId } from 'wagmi'
import { mainnet, base } from 'wagmi/chains'

export function NetworkSwitcher() {
  const chainId = useChainId()
  const { chains, switchChain, isPending } = useSwitchChain()

  return (
    <select
      value={chainId}
      onChange={e => switchChain({ chainId: Number(e.target.value) })}
      disabled={isPending}
    >
      {chains.map(c => (
        <option key={c.id} value={c.id}>{c.name}</option>
      ))}
    </select>
  )
}

Задача 3 — Real-time лента всех Transfer событий USDC

# src/TransferFeed.tsx
import { useWatchContractEvent } from 'wagmi'
import { useState } from 'react'
import { formatUnits } from 'viem'
import { erc20Abi } from './abi'

const USDC = '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48' as const

type Row = { from: string; to: string; amount: string; hash: string }

export function TransferFeed() {
  const [rows, setRows] = useState<Row[]>([])

  useWatchContractEvent({
    address: USDC,
    abi: erc20Abi,
    eventName: 'Transfer',
    onLogs(logs) {
      const newRows = logs.map(l => ({
        from: l.args.from?.slice(0, 8) ?? '',
        to:   l.args.to?.slice(0, 8) ?? '',
        amount: formatUnits(l.args.value ?? 0n, 6),
        hash: l.transactionHash ?? '',
      }))
      setRows(prev => [...newRows, ...prev].slice(0, 30))  // храним последние 30
    },
  })

  return (
    <table>
      <thead><tr><th>from</th><th>to</th><th>amount (USDC)</th></tr></thead>
      <tbody>
        {rows.map(r => (
          <tr key={r.hash + r.from + r.to}>
            <td>{r.from}…</td><td>{r.to}…</td><td>{r.amount}</td>
          </tr>
        ))}
      </tbody>
    </table>
  )
}

# На mainnet USDC «горит» каждый блок — таблица будет обновляться постоянно.
