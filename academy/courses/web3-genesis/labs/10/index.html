Lab 10 · Full dApp: ERC-20 Dashboard

Финальный лаб курса объединяет все навыки предыдущих занятий в один production-ready проект. Вы соберёте ERC-20 Dashboard — полноценный dApp с подключением кошелька, отображением информации о токене, формой трансфера с предпросмотром газа, live-лентой событий, историей транзакций в localStorage и деплоем фронтенда на IPFS через Pinata. Это не учебный пример — это рабочее приложение, которое можно показывать как portfolio-проект.

Цели лаба. После выполнения всех заданий вы сможете: планировать компонентную архитектуру dApp; реализовывать TokenCard с полными метаданными и балансом; строить TransferForm с simulateContract и оценкой газа; интегрировать ленту событий из The Graph или getLogs; хранить историю транзакций в localStorage с актуальными статусами; верстать адаптивный дашборд на CSS Grid в тёмной теме; деплоить сборку на IPFS через Pinata CLI и прописывать ENS contentHash.

Реализуйте TokenCard: читайте все метаданные токена и баланс подключённого аккаунта через один батчевый multicall.

src/components/TokenCard.tsx

import { useReadContracts } from "wagmi";
import { formatUnits } from "viem";
import type { Address } from "viem";

const ERC20_ABI = [
  { name: "name",        type: "function", stateMutability: "view", inputs: [], outputs: [{ type: "string"  }] },
  { name: "symbol",      type: "function", stateMutability: "view", inputs: [], outputs: [{ type: "string"  }] },
  { name: "decimals",    type: "function", stateMutability: "view", inputs: [], outputs: [{ type: "uint8"   }] },
  { name: "totalSupply", type: "function", stateMutability: "view", inputs: [], outputs: [{ type: "uint256" }] },
  { name: "balanceOf",   type: "function", stateMutability: "view",
    inputs: [{ name: "account", type: "address" }], outputs: [{ type: "uint256" }] },
] as const;

interface Props { tokenAddress: Address; account: Address; }

export function TokenCard({ tokenAddress, account }: Props) {
  const { data, isLoading } = useReadContracts({
    contracts: [
      { address: tokenAddress, abi: ERC20_ABI, functionName: "name"        },
      { address: tokenAddress, abi: ERC20_ABI, functionName: "symbol"      },
      { address: tokenAddress, abi: ERC20_ABI, functionName: "decimals"    },
      { address: tokenAddress, abi: ERC20_ABI, functionName: "totalSupply" },
      { address: tokenAddress, abi: ERC20_ABI, functionName: "balanceOf", args: [account] },
    ],
    query: { refetchInterval: 12_000 },
  });

  if (isLoading) return <div className="token-card skeleton">Загрузка...</div>;

  const [name, symbol, decimals, totalSupply, balance] =
    data?.map((d) => d.result) ?? [];

  const dec = decimals as number ?? 18;

  return (
    <div className="token-card">
      <div className="token-header">
        <h2>{name as string}</h2>
        <span className="badge">{symbol as string}</span>
      </div>
      <div className="token-stats">
        <div className="stat">
          <label>Decimals</label>
          <value>{dec}</value>
        </div>
        <div className="stat">
          <label>Total Supply</label>
          <value>{formatUnits(totalSupply as bigint ?? 0n, dec)}</value>
        </div>
        <div className="stat highlight">
          <label>Ваш баланс</label>
          <value>{formatUnits(balance as bigint ?? 0n, dec)} {symbol as string}</value>
        </div>
      </div>
      <div className="token-address">
        <small>Контракт: <code>{tokenAddress}</code></small>
      </div>
    </div>
  );
}

Задание 3

Реализуйте TransferForm с предпросмотром газа через simulateContract и блокировкой кнопки при ошибке симуляции.

src/components/TransferForm.tsx

import { useState, useEffect } from "react";
import {
  useWriteContract, useWaitForTransactionReceipt,
  useEstimateContractGas, usePublicClient,
} from "wagmi";
import { parseUnits, isAddress, formatGwei, formatEther } from "viem";
import type { Address } from "viem";
import toast from "react-hot-toast";

const ERC20_ABI = [
  { name: "transfer", type: "function", stateMutability: "nonpayable",
    inputs: [{ name: "to", type: "address" }, { name: "value", type: "uint256" }],
    outputs: [{ type: "bool" }] },
] as const;

interface Props { tokenAddress: Address; decimals?: number; symbol?: string; }

export function TransferForm({ tokenAddress, decimals = 6, symbol = "TOKEN" }: Props) {
  const [to, setTo]         = useState("");
  const [amount, setAmount] = useState("");
  const [simError, setSimError] = useState<string | null>(null);

  const publicClient = usePublicClient();

  const { writeContract, data: txHash, isPending, error, reset } = useWriteContract();
  const { isLoading: isConfirming, isSuccess } = useWaitForTransactionReceipt({ hash: txHash });

  // Получаем оценку газа при изменении параметров:
  const isValidInput = isAddress(to) && amount && Number(amount) > 0;
  const { data: gasEstimate } = useEstimateContractGas(
    isValidInput
      ? { address: tokenAddress, abi: ERC20_ABI, functionName: "transfer",
          args: [to as Address, parseUnits(amount, decimals)] }
      : undefined
  );

  // Симуляция при изменении полей — предупреждаем до нажатия кнопки:
  useEffect(() => {
    if (!isValidInput || !publicClient) { setSimError(null); return; }
    const run = async () => {
      try {
        await publicClient.simulateContract({
          address: tokenAddress, abi: ERC20_ABI, functionName: "transfer",
          args: [to as Address, parseUnits(amount, decimals)],
        });
        setSimError(null);
      } catch (e: any) {
        setSimError(e?.shortMessage ?? e?.message ?? "Ошибка симуляции");
      }
    };
    const timer = setTimeout(run, 500); // debounce 500ms
    return () => clearTimeout(timer);
  }, [to, amount, publicClient, tokenAddress, decimals]);

  useEffect(() => {
    if (isPending)    toast.loading("Подтвердите в кошельке...", { id: "tx" });
    if (isConfirming) toast.loading("Ожидание блока...", { id: "tx" });
    if (isSuccess)  { toast.success("Трансфер подтверждён!", { id: "tx" }); reset(); }
    if (error)      { toast.error(error.message.slice(0, 80), { id: "tx" }); }
  }, [isPending, isConfirming, isSuccess, error, reset]);

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (simError) return;
    writeContract({ address: tokenAddress, abi: ERC20_ABI, functionName: "transfer",
      args: [to as Address, parseUnits(amount, decimals)] });
  };

  return (
    <div className="transfer-form card">
      <h3>Отправить {symbol}</h3>
      <form onSubmit={handleSubmit}>
        <label>Адрес получателя
          <input value={to} onChange={(e) => setTo(e.target.value)}
            placeholder="0x..." className={to && !isAddress(to) ? "error" : ""} />
        </label>
        <label>Сумма ({symbol})
          <input type="number" value={amount} onChange={(e) => setAmount(e.target.value)}
            placeholder="0.00" min="0" step="0.000001" />
        </label>

        {/* Предпросмотр газа */}
        {gasEstimate && (
          <div className="gas-preview">
            Оценка газа: {gasEstimate.toString()} units
          </div>
        )}

        {/* Предупреждение симуляции */}
        {simError && <p className="sim-error">{simError}</p>}

        <button type="submit" disabled={isPending || isConfirming || !!simError || !isValidInput}>
          {isPending ? "Ожидание подписи..." : isConfirming ? "Подтверждение..." : "Отправить"}
        </button>
      </form>
      {txHash && (
        <p>Tx: <a href={`https://sepolia.etherscan.io/tx/${txHash}`} target="_blank" rel="noopener">
          {txHash.slice(0, 12)}...
        </a></p>
      )}
    </div>
  );
}

import { useQuery } from "urql";
import { formatUnits } from "viem";

// Если The Graph недоступен — fallback через useWatchContractEvent из Lab 09

const RECENT_TRANSFERS = `
  query RecentTransfers {
    transfers(orderBy: blockNumber, orderDirection: desc, first: 20) {
      id
      from { id }
      to   { id }
      amount
      blockNumber
      transactionHash
    }
  }
`;

interface Props { decimals?: number; symbol?: string; }

export function EventFeed({ decimals = 6, symbol = "TOKEN" }: Props) {
  const [result] = useQuery({ query: RECENT_TRANSFERS });

      <h3>Последние трансферы</h3>
      <div className="event-list">
        {transfers.map((tx: any) => (
          <div key={tx.id} className="event-row">

            <span className="event-from">{tx.from.id.slice(0, 8)}...</span>
            <span className="event-arrow">→</span>
            <span className="event-to">{tx.to.id.slice(0, 8)}...</span>
            <span className="event-amount">
              {formatUnits(BigInt(tx.amount), decimals)} {symbol}
            </span>
            <a
              className="event-link"
              href={`https://sepolia.etherscan.io/tx/${tx.transactionHash}`}
              target="_blank"
              rel="noopener"
            >
              ↗
            </a>
          </div>
        ))}
      </div>
    </div>
  );
}

Задание 5

Реализуйте TxHistory: сохраняйте отправленные транзакции в localStorage и обновляйте их статусы.

src/hooks/useTxHistory.ts

import { useState, useEffect, useCallback } from "react";
import { usePublicClient } from "wagmi";

export interface TxRecord {
  hash:      `0x${string}`;
  to:        string;
  amount:    string;
  symbol:    string;
  status:    "pending" | "success" | "reverted";
  timestamp: number;
}

const STORAGE_KEY = "erc20-dashboard-tx-history";

export function useTxHistory() {
  const publicClient = usePublicClient();
  const [history, setHistory] = useState<TxRecord[]>(() => {
    try {
      return JSON.parse(localStorage.getItem(STORAGE_KEY) ?? "[]");
    } catch { return []; }
  });

  // Сохранять в localStorage при каждом изменении:
  useEffect(() => {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(history));
  }, [history]);

  // Добавить новую транзакцию:
  const addTx = useCallback((tx: Omit<TxRecord, "status" | "timestamp">) => {
    const record: TxRecord = { ...tx, status: "pending", timestamp: Date.now() };
    setHistory((prev) => [record, ...prev].slice(0, 50)); // max 50 записей
  }, []);

  // Обновить статус по hash:
  const updateStatus = useCallback(
    (hash: `0x${string}`, status: TxRecord["status"]) => {
      setHistory((prev) =>
        prev.map((tx) => (tx.hash === hash ? { ...tx, status } : tx))
      );
    },
    []
  );

  // При старте приложения — проверить статусы pending транзакций:
  useEffect(() => {
    if (!publicClient) return;
    const pendingTxs = history.filter((tx) => tx.status === "pending");
    pendingTxs.forEach(async (tx) => {
      try {
        const receipt = await publicClient.getTransactionReceipt({ hash: tx.hash });
        updateStatus(tx.hash, receipt.status === "success" ? "success" : "reverted");
      } catch {
        // Транзакция ещё в mempool или выпала — оставляем pending
      }
    });
  }, [publicClient]); // eslint-disable-line react-hooks/exhaustive-deps

  return { history, addTx, updateStatus };
}

Проверка развёртывания

ШагПроверкаИнструмент
IPFS доступен Открывается https://ipfs.io/ipfs/QmYour.../ Браузер
ENS резолвится ethers.getResolver("mydapp.eth") возвращает address viem / ethers.js
ENS открывается Браузер с IPFS-расширением открывает mydapp.eth Brave / MetaMask Snaps
Pin активен Пин не удалён из аккаунта Pinata app.pinata.cloud
Децентрализованность. После деплоя на IPFS и привязки к ENS ваш dApp доступен без центрального сервера: IPFS хранит файлы контентно-адресуемо (по хэшу), ENS обеспечивает человекочитаемый адрес. Единственная зависимость от инфраструктуры — RPC-нода для блокчейн-запросов. Используйте fallback([http(infura), http(alchemy)]) для максимальной устойчивости.
