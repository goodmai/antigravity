Lab 08 · viem: JSON-RPC Client

viem — современная TypeScript-библиотека для работы с EVM-сетями. В отличие от ethers.js v5, viem написан с нуля с прицелом на tree-shaking, нативный BigInt, строгую типизацию ABI и минимальный bundle size. Вместо одного монолитного класса Provider здесь две специализированные сущности: publicClient для чтения данных и walletClient для подписи и отправки транзакций. В этом лабе вы освоите весь жизненный цикл: от чтения блока до ожидания квитанции о транзакции.

Цели лаба. После выполнения всех заданий вы сможете: создавать publicClient и выполнять базовые RPC-запросы; читать данные ERC-20 контракта через readContract; получать события через getLogs с фильтром по блокам; декодировать event logs с помощью decodeEventLog; использовать simulateContract для предпросмотра транзакций; создавать walletClient и отправлять реальные транзакции; ожидать квитанцию и извлекать все emitted events.

src/01-basic.ts

import { createPublicClient, http, formatEther } from "viem";
import { sepolia } from "viem/chains";

// publicClient — только чтение, не требует подписи
const client = createPublicClient({
  chain: sepolia,
  transport: http("https://sepolia.infura.io/v3/YOUR_KEY"),
  // Можно использовать публичный RPC:
  // transport: http("https://rpc.sepolia.org"),
});

async function main() {
  // eth_blockNumber
  const blockNumber = await client.getBlockNumber();
  console.log("Текущий блок:", blockNumber);

  // eth_getBalance
  const address = "0x70997970C51812dc3A010C7d01b50e0d17dc79C8";
  const balanceWei = await client.getBalance({ address });
  console.log(`Баланс ${address}:`, formatEther(balanceWei), "ETH");

  // eth_getBlock
  const block = await client.getBlock({ blockNumber });
  console.log("Время блока:", new Date(Number(block.timestamp) * 1000).toISOString());
  console.log("Транзакций в блоке:", block.transactions.length);
}

main();

Задание 2

Прочитайте метаданные ERC-20 токена через readContract: name, symbol, decimals, totalSupply и баланс конкретного адреса.

src/02-read-contract.ts

import { createPublicClient, http, formatUnits } from "viem";
import { sepolia } from "viem/chains";

const client = createPublicClient({
  chain: sepolia,
  transport: http("https://rpc.sepolia.org"),
});

// Минимальный ABI для ERC-20 (только нужные нам функции):
const ERC20_ABI = [
  { name: "name",        type: "function", stateMutability: "view",
    inputs: [], outputs: [{ type: "string" }] },
  { name: "symbol",      type: "function", stateMutability: "view",
    inputs: [], outputs: [{ type: "string" }] },
  { name: "decimals",    type: "function", stateMutability: "view",
    inputs: [], outputs: [{ type: "uint8" }] },
  { name: "totalSupply", type: "function", stateMutability: "view",
    inputs: [], outputs: [{ type: "uint256" }] },
  { name: "balanceOf",   type: "function", stateMutability: "view",
    inputs: [{ name: "account", type: "address" }],
    outputs: [{ type: "uint256" }] },
] as const;

// USDC на Sepolia:
const TOKEN_ADDRESS = "0x1c7D4B196Cb0C7B01d743Fbc6116a902379C7238";
const MY_ADDRESS   = "0x70997970C51812dc3A010C7d01b50e0d17dc79C8";

async function main() {
  // Несколько читающих вызовов можно объединить через multicall:
  const [name, symbol, decimals, totalSupply, myBalance] = await Promise.all([
    client.readContract({ address: TOKEN_ADDRESS, abi: ERC20_ABI, functionName: "name" }),
    client.readContract({ address: TOKEN_ADDRESS, abi: ERC20_ABI, functionName: "symbol" }),
    client.readContract({ address: TOKEN_ADDRESS, abi: ERC20_ABI, functionName: "decimals" }),
    client.readContract({ address: TOKEN_ADDRESS, abi: ERC20_ABI, functionName: "totalSupply" }),
    client.readContract({
      address: TOKEN_ADDRESS, abi: ERC20_ABI,
      functionName: "balanceOf",
      args: [MY_ADDRESS],
    }),
  ]);

  console.log(`${name} (${symbol})`);
  console.log(`Decimals: ${decimals}`);
  console.log(`Total Supply: ${formatUnits(totalSupply, decimals)}`);
  console.log(`My balance: ${formatUnits(myBalance, decimals)} ${symbol}`);
}

main();

Задание 3

Используйте getLogs для получения всех событий Transfer за последние 1000 блоков для выбранного токена.

src/03-get-logs.ts

import { createPublicClient, http, parseAbiItem } from "viem";
import { sepolia } from "viem/chains";

const client = createPublicClient({
  chain: sepolia,
  transport: http("https://rpc.sepolia.org"),
});

const TOKEN_ADDRESS = "0x1c7D4B196Cb0C7B01d743Fbc6116a902379C7238";

async function main() {
  const currentBlock = await client.getBlockNumber();
  const fromBlock = currentBlock - 1000n;

  // getLogs — это eth_getLogs под капотом
  const logs = await client.getLogs({
    address: TOKEN_ADDRESS,
    // parseAbiItem создаёт фрагмент ABI из человекочитаемой сигнатуры:
    event: parseAbiItem("event Transfer(address indexed from, address indexed to, uint256 value)"),
    fromBlock,
    toBlock: currentBlock,
  });

  console.log(`Transfer события с блока ${fromBlock} по ${currentBlock}:`);
  console.log(`Всего: ${logs.length}`);

  // Первые 5 для preview:
  for (const log of logs.slice(0, 5)) {
    console.log({
      blockNumber: log.blockNumber,
      txHash: log.transactionHash,
      from: log.args.from,
      to:   log.args.to,
      // value в raw формате (BigInt, без decimals)
      value: log.args.value?.toString(),
    });
  }
}

main();
Лимиты RPC. Большинство публичных нод ограничивают eth_getLogs диапазоном в 2 000 – 10 000 блоков за запрос. Для больших диапазонов разбивайте на чанки или используйте платные ноды (Infura, Alchemy) с расширенными лимитами.

Задание 4

Декодируйте сырые event logs с помощью decodeEventLog и отобразите результаты в виде форматированной таблицы.

src/04-decode-logs.ts

import {
  createPublicClient, http, decodeEventLog, formatUnits, parseAbiItem
} from "viem";
import { sepolia } from "viem/chains";

const client = createPublicClient({
  chain: sepolia,
  transport: http("https://rpc.sepolia.org"),
});

const ERC20_ABI = [
  {
    name: "Transfer",
    type: "event",
    inputs: [
      { name: "from",  type: "address", indexed: true },
      { name: "to",    type: "address", indexed: true },
      { name: "value", type: "uint256", indexed: false },
    ],
  },
  {
    name: "Approval",
    type: "event",
    inputs: [
      { name: "owner",   type: "address", indexed: true },
      { name: "spender", type: "address", indexed: true },
      { name: "value",   type: "uint256", indexed: false },
    ],
  },
] as const;

const TOKEN_ADDRESS = "0x1c7D4B196Cb0C7B01d743Fbc6116a902379C7238";
const DECIMALS = 6; // USDC

async function main() {
  const currentBlock = await client.getBlockNumber();
  const rawLogs = await client.getLogs({
    address: TOKEN_ADDRESS,
    fromBlock: currentBlock - 500n,
    toBlock:   currentBlock,
  });

  console.log(`Получено ${rawLogs.length} логов, декодируем...\n`);

  // Таблица в консоли:
  console.log(
    "Block".padEnd(10),
    "Event".padEnd(10),
    "From".padEnd(44),
    "To".padEnd(44),
    "Amount"
  );
  console.log("-".repeat(120));

  for (const log of rawLogs) {
    try {
      // decodeEventLog разбирает topics и data по ABI
      const decoded = decodeEventLog({
        abi: ERC20_ABI,
        data: log.data,
        topics: log.topics,
      });

      if (decoded.eventName === "Transfer") {
        const args = decoded.args as { from: string; to: string; value: bigint };
        console.log(
          log.blockNumber?.toString().padEnd(10),
          decoded.eventName.padEnd(10),
          args.from.padEnd(44),
          args.to.padEnd(44),
          formatUnits(args.value, DECIMALS)
        );
      }
    } catch {
      // Пропускаем нераспознанные события (если ABI неполный)
    }
  }
}

main();

Задание 5

Используйте simulateContract, чтобы предпросмотреть вызов transfer() — проверить, не откатится ли транзакция, и получить оценку газа.

src/05-simulate.ts

import { createPublicClient, http, parseUnits } from "viem";
import { sepolia } from "viem/chains";

const client = createPublicClient({
  chain: sepolia,
  transport: http("https://rpc.sepolia.org"),
});

const ERC20_ABI = [
  {
    name: "transfer",
    type: "function",
    stateMutability: "nonpayable",
    inputs: [
      { name: "to",    type: "address" },
      { name: "value", type: "uint256" },
    ],
    outputs: [{ type: "bool" }],
  },
] as const;

const TOKEN_ADDRESS = "0x1c7D4B196Cb0C7B01d743Fbc6116a902379C7238";
const SENDER    = "0xYOUR_ADDRESS";  // адрес с балансом USDC на Sepolia
const RECIPIENT = "0x70997970C51812dc3A010C7d01b50e0d17dc79C8";

async function main() {
  const amount = parseUnits("1.0", 6); // 1 USDC (6 decimals)

  try {
    // simulateContract = eth_call, симулирует транзакцию без отправки
    const { result, request } = await client.simulateContract({
      address: TOKEN_ADDRESS,
      abi: ERC20_ABI,
      functionName: "transfer",
      args: [RECIPIENT, amount],
      account: SENDER,
    });

    console.log("Симуляция успешна. Возвращаемое значение:", result); // true
    console.log("Запрос готов к отправке:", request);

    // Оценка газа для реальной транзакции:
    const gasEstimate = await client.estimateContractGas({
      address: TOKEN_ADDRESS,
      abi: ERC20_ABI,
      functionName: "transfer",
      args: [RECIPIENT, amount],
      account: SENDER,
    });
    console.log("Оценка газа:", gasEstimate.toString());

  } catch (err) {
    // Если симуляция откатывается — узнаём причину до отправки реальной tx
    console.error("Симуляция провалилась:", err);
  }
}

main();

Задание 6

Создайте walletClient с приватным ключом и отправьте тестовый трансфер на Sepolia.

Безопасность. Никогда не храните приватные ключи с реальными средствами в коде. Используйте только тестовые ключи на тестовых сетях (Sepolia). Получите тестовый ETH на faucet.sepolia.dev.

src/06-send.ts

import {
  createPublicClient, createWalletClient,
  http, parseUnits,
  privateKeyToAccount,
} from "viem";
import { sepolia } from "viem/chains";

const RPC_URL    = "https://rpc.sepolia.org";
const PRIVATE_KEY = process.env.PRIVATE_KEY as `0x${string}`;

const account = privateKeyToAccount(PRIVATE_KEY);

const publicClient = createPublicClient({
  chain: sepolia,
  transport: http(RPC_URL),
});

const walletClient = createWalletClient({
  account,
  chain: sepolia,
  transport: http(RPC_URL),
});

const ERC20_ABI = [
  {
    name: "transfer",
    type: "function",
    stateMutability: "nonpayable",
    inputs: [
      { name: "to",    type: "address" },
      { name: "value", type: "uint256" },
    ],
    outputs: [{ type: "bool" }],
  },
] as const;

const TOKEN_ADDRESS = "0x1c7D4B196Cb0C7B01d743Fbc6116a902379C7238";
const RECIPIENT     = "0x70997970C51812dc3A010C7d01b50e0d17dc79C8";

async function main() {
  console.log("Отправитель:", account.address);

  const amount = parseUnits("0.001", 6); // 0.001 USDC

  // Шаг 1: симуляция (проверяем баланс и логику)
  const { request } = await publicClient.simulateContract({
    address: TOKEN_ADDRESS,
    abi: ERC20_ABI,
    functionName: "transfer",
    args: [RECIPIENT, amount],
    account,
  });

  // Шаг 2: отправка (walletClient подписывает и отправляет)
  const txHash = await walletClient.writeContract(request);
  console.log("Транзакция отправлена:", txHash);
  console.log("Смотреть: https://sepolia.etherscan.io/tx/" + txHash);
}

main();

Задание 7

Дождитесь квитанции транзакции с помощью waitForTransactionReceipt и выведите все события, эмитированные в ходе транзакции.

src/07-receipt.ts

import {
  createPublicClient, http,
  decodeEventLog, formatUnits,
  waitForTransactionReceipt,
} from "viem";
import { sepolia } from "viem/chains";

const client = createPublicClient({
  chain: sepolia,
  transport: http("https://rpc.sepolia.org"),
});

const ERC20_ABI = [
  {
    name: "Transfer",
    type: "event",
    inputs: [
      { name: "from",  type: "address", indexed: true },
      { name: "to",    type: "address", indexed: true },
      { name: "value", type: "uint256", indexed: false },
    ],
  },
  {
    name: "Approval",
    type: "event",
    inputs: [
      { name: "owner",   type: "address", indexed: true },
      { name: "spender", type: "address", indexed: true },
      { name: "value",   type: "uint256", indexed: false },
    ],
  },
] as const;

async function waitAndDecode(txHash: `0x${string}`) {
  console.log("Ожидание квитанции для:", txHash);

  // Ждём включения транзакции в блок:
  const receipt = await waitForTransactionReceipt(client, {
    hash: txHash,
    // confirmations: 1 — ждём 1 подтверждение (по умолчанию)
    // timeout: 60_000  — таймаут в мс
  });

  console.log("\n=== Квитанция ===");
  console.log("Статус:", receipt.status);         // "success" или "reverted"
  console.log("Блок:", receipt.blockNumber);
  console.log("Использовано газа:", receipt.gasUsed);
  console.log("Эффективная цена газа:", receipt.effectiveGasPrice, "wei");
  console.log("Стоимость транзакции:",
    formatUnits(receipt.gasUsed * receipt.effectiveGasPrice, 18), "ETH");

  console.log(`\nСобытий в транзакции: ${receipt.logs.length}`);

  // Декодируем каждый лог:
  for (const log of receipt.logs) {
    try {
      const decoded = decodeEventLog({
        abi: ERC20_ABI,
        data: log.data,
        topics: log.topics,
      });
      console.log(`\nСобытие: ${decoded.eventName}`);
      console.log("Аргументы:", decoded.args);
    } catch {
      console.log("\nНеизвестное событие от:", log.address);
    }
  }
}

// Замените на реальный txHash из Задания 6:
waitAndDecode("0xYOUR_TX_HASH");
