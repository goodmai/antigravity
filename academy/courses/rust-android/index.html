Rust on Android 🦀

Объединённый курс «Rust on Android» — путь от первого fn main() до production-grade интеграции Rust в Android-приложение. В курс вошёл материал Comprehensive Rust by Google (фундамент языка) и новые модули по NDK, JNI, UniFFI, безопасности и поставке через AGP / Play Store. Каждый урок содержит редактируемую Rust Playground-ячейку с самопроверкой через assert! / assert_eq!, а лабораторные работы дают законченные мини-проекты со ссылками на исходники.

Как проходить курс. Читайте текст — затем запускайте песочницу кнопкой ▶ Run. Если все assertions проходят — ячейка становится зелёной; иначе Rust-компилятор покажет ошибку. Лабораторные выполняются по шагам и завершаются git-коммитом / APK-сборкой.

Источники и материалы для углубления

  • The Rust Programming Language — официальная книга Steve Klabnik & Carol Nichols.
  • Comprehensive Rust by Google — Apache 2.0 / CC BY 4.0, основа для модулей I–II.
  • Rust by Example — рабочие сниппеты на каждый концепт.
  • The Rustonomicon — unsafe Rust, FFI, layout.
  • Android Rust documentation (AOSP) — официальное руководство Google.
  • Android NDK Guides — toolchain, ABIs, Bitmap API.
  • UniFFI User Guide — биндинги Rust↔Kotlin/Swift/Python.
  • jni-rs crate docs — низкоуровневый JNI API в Rust.
  • cargo-ndk и rust-android-gradle — build-pipelines.
  • Tokio Tutorial — async-runtime.
  • Async Book — теория async/.await и future'ов.
  • Rust in the Android platform — пост Google Security Blog.
