Rust API (UniFFI proc-macros)

#[derive(uniffi::Object)]
pub struct Vault { /* … */ }

#[uniffi::export]
impl Vault {
    #[uniffi::constructor]
    pub fn open(path: String, master: String) -> Result<Arc<Self>, VaultError>;
    pub fn add(&self, label: String, secret: String) -> Result<(), VaultError>;
    pub fn get(&self, label: String) -> Result<String, VaultError>;
    pub fn list(&self) -> Vec<String>;
    pub fn lock(&self);    // zeroize ключа в памяти
}

Криптостек

  • Argon2id (argon2 crate) для деривации ключа из пароля: memory_cost = 64 MiB, iterations = 3, parallelism = 1.
  • AES-256-GCM (aes-gcm) для шифрования каждого секрета, nonce = 12 случайных байт из OsRng.
  • zeroize: ключ обёрнут в Zeroizing<[u8; 32]>, стирается в памяти при Drop.
  • Constant-time compare через subtle::ConstantTimeEq.

UI на Compose

@Composable
fun VaultScreen(vm: VaultViewModel = viewModel()) {
    val state by vm.state.collectAsState()
    when (val s = state) {
        VaultState.Locked   -> LockScreen(onUnlock = vm::unlockWithBiometrics)
        is VaultState.Open  -> SecretsList(s.labels,
                                onClick = vm::reveal,
                                onAdd   = vm::add)
        is VaultState.Error -> ErrorBanner(s.message)
    }
}

Biometric unlock

BiometricPrompt(this, mainExecutor, object : BiometricPrompt.AuthenticationCallback() {
    override fun onAuthenticationSucceeded(r: BiometricPrompt.AuthenticationResult) {
        val masterKey = androidKeyStore.decryptDek(r.cryptoObject)
        vm.openVault(masterKey)
    }
}).authenticate(promptInfo, BiometricPrompt.CryptoObject(cipher))

Хитрость: сам мастер-пароль никогда не покидает enclave — Keystore хранит лишь DEK (data encryption key), а Rust работает с DEK как с непрозрачным [u8; 32].

CI / Release

Используйте workflow из Lesson 21:

  • cargo audit, cargo deny, cargo test
  • cargo ndk … build --release для 3 ABI
  • ./gradlew bundleRelease
  • upload-google-play action → Internal track

Чек-лист security review

  • ✅ #![forbid(unsafe_code)] в Rust-ядре.
  • ✅ Argon2 params не меньше OWASP recommendations.
  • ✅ Nonce уникальный на каждое шифрование.
  • ✅ Все ключи в памяти — Zeroizing.
  • ✅ Биометрия требует BIOMETRIC_STRONG (Class 3).
  • ✅ Backup отключён (android:allowBackup="false").
  • ✅ FLAG_SECURE на экране секретов.

Эмулируем derive_key через Argon2

Дисклеймер: код в playground'е — это демонстрация интерфейса. В production используйте argon2::Argon2::new(...) и НЕ изобретайте свои KDF. См. password-hashing.net.
