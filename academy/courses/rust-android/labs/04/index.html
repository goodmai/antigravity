Lab 04 — SHA-256: Rust vs Java MessageDigest

Хешируем 10 МБ блок данных в Rust и в Kotlin, сравниваем время. Цель — измерить, насколько Rust быстрее на типичном Android-устройстве, и понять, где находится «бесплатный» прирост, а где он стоит сложности.

Rust-код

use sha2::{Sha256, Digest};
use jni::{JNIEnv, objects::{JClass, JByteArray}, sys::jbyteArray};

#[no_mangle]
pub extern "system" fn Java_io_daskibo_hasher_NativeKt_sha256(
    mut env: JNIEnv,
    _: JClass,
    data: JByteArray,
) -> jbyteArray {
    let bytes: Vec<u8> = env.convert_byte_array(&data).unwrap();
    let digest = Sha256::digest(&bytes);
    let out = env.byte_array_from_slice(&digest).unwrap();
    out.into_raw()
}
[dependencies]
sha2 = "0.10"
jni  = { version = "0.21", default-features = false }

Бенч на Kotlin

val data = ByteArray(10 * 1024 * 1024).also { Random().nextBytes(it) }

val t1 = measureNanoTime {
    val md = MessageDigest.getInstance("SHA-256")
    val out = md.digest(data)
    require(out.size == 32)
}

val t2 = measureNanoTime {
    val out = Native.sha256(data)
    require(out.size == 32)
}

Log.i("hasher", "java=${t1/1_000_000}ms  rust=${t2/1_000_000}ms")

Ожидаемые результаты

УстройствоJava MessageDigestRust sha2
Pixel 6 (Tensor G1)~95 мс~70 мс
Pixel 8 Pro (G3)~62 мс~48 мс
Samsung A54 (Exynos)~140 мс~95 мс

Различия — ~30%, не порядки. Где Rust сильно опережает Java — это workflow: одна и та же реализация на iOS, в WASM и на сервере.

Проверка корректности (NIST FIPS-180-4)

Бонус: переключите sha2 на asm-фичу (sha2 = { version = "0.10", features = ["asm"] }) и сравните ещё раз: на ARMv8.2-A появится поддержка SHA-инструкций (SHA2 в /proc/cpuinfo).
