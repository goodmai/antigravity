Lab 05 — Greyscale-фильтр через Android Bitmap NDK

Передача Bitmap'ов через JNI «обычным» путём — это byte[]-копия, которая на 4K-картинке съест 30 МБ. У Android есть Bitmap NDK API: Rust получает указатель на пиксели напрямую.

Rust

use jni::{JNIEnv, objects::{JClass, JObject}};
use ndk_sys::{AndroidBitmapInfo, AndroidBitmap_getInfo,
               AndroidBitmap_lockPixels, AndroidBitmap_unlockPixels,
               ANDROID_BITMAP_FORMAT_RGBA_8888, ANDROID_BITMAP_RESULT_SUCCESS};
use std::ffi::c_void;

#[no_mangle]
pub extern "system" fn Java_io_daskibo_img_NativeKt_greyscale(
    mut env: JNIEnv,
    _: JClass,
    bitmap: JObject,
) {
    let env_ptr = env.get_raw();
    let mut info = AndroidBitmapInfo::default();
    unsafe {
        if AndroidBitmap_getInfo(env_ptr.cast(), bitmap.as_raw().cast(), &mut info) != ANDROID_BITMAP_RESULT_SUCCESS as i32 {
            log::error!("getInfo failed"); return;
        }
        if info.format != ANDROID_BITMAP_FORMAT_RGBA_8888 as u32 {
            log::error!("expected RGBA_8888, got {}", info.format); return;
        }

        let mut ptr: *mut c_void = std::ptr::null_mut();
        AndroidBitmap_lockPixels(env_ptr.cast(), bitmap.as_raw().cast(), &mut ptr);
        let pixels = std::slice::from_raw_parts_mut(ptr as *mut u8,
            (info.stride * info.height) as usize);

        for px in pixels.chunks_exact_mut(4) {
            // BT.601 luma:
            let y = (0.299 * px[0] as f32 + 0.587 * px[1] as f32 + 0.114 * px[2] as f32) as u8;
            px[0] = y; px[1] = y; px[2] = y; // alpha не трогаем
        }

        AndroidBitmap_unlockPixels(env_ptr.cast(), bitmap.as_raw().cast());
    }
}

Kotlin

val bmp = BitmapFactory.decodeResource(resources, R.drawable.sample)
    .copy(Bitmap.Config.ARGB_8888, true) // mutable!

Native.greyscale(bmp)        // ← мутирует in-place

imageView.setImageBitmap(bmp)

Почему это быстрее

  • Нет копирования byte[] через JNI (0 KB трафика).
  • Rust работает с raw-памятью под безопасной обёрткой slice::from_raw_parts_mut.
  • LLVM SIMD-векторизует цикл на ARM NEON.

Эмуляция фильтра в playground'е

Бонус: добавьте параметр strength: f32 от 0.0 (без эффекта) до 1.0 (полный Ч/Б) и сделайте линейную интерполяцию.
