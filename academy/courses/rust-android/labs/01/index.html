Lab 01 — Hello Rust JNI

Цель — собрать минимально жизнеспособное Android-приложение, которое вызывает Rust-функцию и отображает её результат на экране.

Уровень
Beginner
Время
~45 мин
Уроки
13, 14, 15
Артефакт
APK с Rust-функцией

Что вы научитесь делать

  • Создавать Cargo-проект с cdylib для Android.
  • Писать JNI-функцию вручную через крейт jni.
  • Собирать .so для arm64-v8a через cargo-ndk.
  • Подключать библиотеку в Android Studio и вызывать её из Kotlin.

Предварительные требования

  • Android Studio Iguana или новее.
  • NDK r26+ через SDK Manager.
  • rustup target add aarch64-linux-android.
  • cargo install cargo-ndk.

Шаги

Создать пустой Android-проект

File → New → New Project → Empty Activity. minSdk = 24, язык = Kotlin, package = io.daskibo.hello.

Добавить Rust-crate

cd <project-root>
cargo new --lib rust-core
cd rust-core

Замените Cargo.toml:

[package]
name    = "hello"
version = "0.1.0"
edition = "2021"

[lib]
crate-type = ["cdylib"]

[dependencies]
jni = { version = "0.21", default-features = false }

Написать JNI-функцию

// rust-core/src/lib.rs
use jni::JNIEnv;
use jni::objects::JClass;
use jni::sys::jstring;

#[no_mangle]
pub extern "system" fn Java_io_daskibo_hello_NativeKt_greet(
    mut env: JNIEnv,
    _: JClass,
) -> jstring {
    env.new_string("Hello from Rust!").unwrap().into_raw()
}

Собрать .so

cargo ndk -t arm64-v8a -o ../app/src/main/jniLibs build --release

Проверьте, что появился app/src/main/jniLibs/arm64-v8a/libhello.so.

Загрузить из Kotlin

// app/src/main/java/io/daskibo/hello/Native.kt
package io.daskibo.hello

object Native {
    init { System.loadLibrary("hello") }
    external fun greet(): String
}

Использовать в Activity

// MainActivity.kt
class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        val tv = TextView(this).apply { textSize = 24f }
        tv.text = Native.greet()    // ← "Hello from Rust!"
        setContentView(tv)
    }
}

Запустить

Поднимите Pixel-эмулятор (arm64 или x86_64 — соберите .so для соответствующего ABI). На экране — текст из Rust.

Проверка эталонной строки

Бонус: добавьте параметр name: String в JNI и возвращайте "Hello, {name}!". Помните про env.get_string(&input)?.into().
