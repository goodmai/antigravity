Lab 10 — Интеграция Rust в AGP через rust-android-gradle

В предыдущих лабах мы вручную звали cargo ndk. Это работает, но забывается. Подключим mozilla/rust-android-gradle: Gradle сам поставит таргеты, вызовет cargo, положит .so в нужный jniLibs.

Уровень
Intermediate
Время
~60 мин
Уроки
13, 21
Артефакт
Build, где ./gradlew assembleRelease делает всё сам

Project-level build.gradle.kts

plugins {
    id("com.android.application") version "8.5.0" apply false
    id("org.jetbrains.kotlin.android") version "2.0.0" apply false
    id("org.mozilla.rust-android-gradle.rust-android") version "0.9.4" apply false
}

app/build.gradle.kts

plugins {
    id("com.android.application")
    id("org.jetbrains.kotlin.android")
    id("org.mozilla.rust-android-gradle.rust-android")
}

android {
    namespace = "io.daskibo.app"
    compileSdk = 34
    defaultConfig {
        applicationId = "io.daskibo.app"
        minSdk = 24
        targetSdk = 34
        ndk { abiFilters += listOf("arm64-v8a", "x86_64") }
    }
}

cargo {
    module      = "../rust-core"             // путь к Rust-crate'у
    libname     = "daskibo"
    targets     = listOf("arm64", "x86_64")
    profile     = "release"
    pythonCommand = "python3"
    extraCargoBuildArguments = listOf("--locked")
}

// связываем cargoBuild с merge JniLibs:
tasks.matching { it.name.matches(Regex("merge.*JniLibFolders")) }.configureEach {
    inputs.dir(layout.buildDirectory.dir("rustJniLibs/android"))
    dependsOn("cargoBuild")
}

Структура проекта

my-app/
├─ app/
│  └─ build.gradle.kts
├─ rust-core/
│  ├─ Cargo.toml
│  └─ src/lib.rs
├─ build.gradle.kts
└─ settings.gradle.kts

Запуск

./gradlew :app:assembleRelease   # сначала cargoBuild, потом APK
./gradlew :app:installDebug      # на устройство

В логе вы увидите :app:cargoBuildArm64 и :app:cargoBuildX86_64. Если cargo упал — Gradle сразу остановит сборку, не дойдя до AGP.

Совместимость версий

AGPrust-android-gradleNDK
8.5.x0.9.4+r26d / r27
8.2.x0.9.3r25c / r26b
7.4.x0.9.0r23c

Что Gradle складывает в jniLibs

Бонус: заведите ./gradlew rustCheck-таск, который запускает cargo clippy -D warnings до сборки. Это «зелёный CI на коленке».
