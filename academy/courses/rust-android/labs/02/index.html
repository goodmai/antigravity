Lab 02 — CLI-утилита под arm64-v8a

Цель — собрать Rust-бинарь, который запускается на Android-устройстве через ADB-shell (без всякого UI), и понять, какие отличия Android от обычного Linux.

Уровень
Beginner+
Время
~30 мин
Уроки
13
Артефакт
ELF-бинарь, исполняемый из adb shell

Шаги

Создать проект

cargo new androidstats --bin
cd androidstats

Код утилиты

// src/main.rs
use std::env;
use std::fs;

fn main() {
    let arch = env::consts::ARCH;
    let kernel = fs::read_to_string("/proc/version").unwrap_or_default();
    let mem = fs::read_to_string("/proc/meminfo").unwrap_or_default();
    let total = mem.lines().find(|l| l.starts_with("MemTotal:")).unwrap_or("MemTotal: ?");

    println!("arch:   {arch}");
    println!("kernel: {}", kernel.lines().next().unwrap_or("?"));
    println!("{total}");
}

Кросс-сборка

rustup target add aarch64-linux-android

cat >> .cargo/config.toml << 'EOF'
[target.aarch64-linux-android]
linker = "$ANDROID_NDK_HOME/toolchains/llvm/prebuilt/linux-x86_64/bin/aarch64-linux-android24-clang"
EOF

cargo build --target aarch64-linux-android --release

Залить на устройство и запустить

adb push target/aarch64-linux-android/release/androidstats /data/local/tmp/
adb shell chmod +x /data/local/tmp/androidstats
adb shell /data/local/tmp/androidstats

# arch:   aarch64
# kernel: Linux version 6.1.43-android14-11-...
# MemTotal: 8112700 kB

Что отличается от обычного Linux

  • Bionic, не glibc. Меньше POSIX-фич, нет getpwnam в полном виде.
  • SELinux: даже chmod +x в /data/local/tmp может не позволить exec — используйте shell-домены.
  • На Android 11+ /sdcard для исполнения недоступен — только /data/local/tmp или путь приложения.
