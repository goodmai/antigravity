Lab 07 — UniFFI: Note Store на 50 строках

В этой лабе мы откажемся от ручного JNI и соберём идиоматичный Kotlin API через UniFFI. На выходе — типизированный NoteStore с эксепшенами Kotlin, который вы не отличите от написанного вручную.

src/lib.rs

use std::sync::Mutex;

#[derive(uniffi::Error, Debug, thiserror::Error)]
pub enum NoteError {
    #[error("note not found")] NotFound,
    #[error("note empty")]     Empty,
}

#[derive(uniffi::Object)]
pub struct NoteStore { inner: Mutex<Vec<String>> }

#[uniffi::export]
impl NoteStore {
    #[uniffi::constructor]
    pub fn new() -> std::sync::Arc<Self> {
        std::sync::Arc::new(Self { inner: Mutex::default() })
    }
    pub fn add(&self, body: String) -> Result<(), NoteError> {
        if body.trim().is_empty() { return Err(NoteError::Empty); }
        self.inner.lock().unwrap().push(body);
        Ok(())
    }
    pub fn get(&self, idx: u32) -> Result<String, NoteError> {
        self.inner.lock().unwrap().get(idx as usize).cloned().ok_or(NoteError::NotFound)
    }
    pub fn count(&self) -> u32 { self.inner.lock().unwrap().len() as u32 }
}

uniffi::setup_scaffolding!();

Сборка биндингов

# 1. .so для arm64
cargo ndk -t arm64-v8a -o app/src/main/jniLibs build --release

# 2. Kotlin-файлы
cargo run --release --bin uniffi-bindgen -- generate \
    --library target/aarch64-linux-android/release/libnotes.so \
    --language kotlin \
    --out-dir app/src/main/java/io/daskibo/notes

Kotlin: использование

import io.daskibo.notes.*

val store = NoteStore()
try {
    store.add("Купить молоко")
    store.add("")           // → NoteException.Empty
} catch (e: NoteException) {
    Log.w("notes", "add failed: $e")
}

val first = store.`get`(0u)   // "Купить молоко"
val total = store.count()     // 1

Что сгенерировал UniFFI «под капотом»

  • Kotlin-класс NoteStore с JNA-биндингами к нашему .so.
  • Sealed class NoteException с подклассами NotFound и Empty.
  • Хелперы для конвертации String ↔ RustBuffer, UInt ↔ u32.
  • FfiConverter'ы — поэтому никаких ручных JNI-сигнатур.
