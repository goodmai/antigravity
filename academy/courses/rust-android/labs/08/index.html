Lab 08 — rusqlite и миграции на Android

У Android есть свой SQLiteOpenHelper, но если ваше Rust-ядро должно работать кросс-платформенно (iOS, server), правильнее иметь одну реализацию репозитория на Rust. Лаба показывает, как подключить rusqlite с bundled-SQLite (без зависимости от системного libsqlite).

Создание Repository

use rusqlite::{Connection, params};
use std::sync::Mutex;

#[derive(uniffi::Error, Debug, thiserror::Error)]
pub enum DbError {
    #[error("io: {0}")]   Io(String),
    #[error("sql: {0}")]  Sql(String),
}
impl From<rusqlite::Error> for DbError {
    fn from(e: rusqlite::Error) -> Self { DbError::Sql(e.to_string()) }
}

#[derive(uniffi::Object)]
pub struct Notes { conn: Mutex<Connection> }

#[uniffi::export]
impl Notes {
    #[uniffi::constructor]
    pub fn open(path: String) -> Result<std::sync::Arc<Self>, DbError> {
        let conn = Connection::open(&path).map_err(DbError::from)?;
        conn.execute_batch(r#"
            CREATE TABLE IF NOT EXISTS notes (
                id    INTEGER PRIMARY KEY AUTOINCREMENT,
                body  TEXT NOT NULL,
                ts    INTEGER NOT NULL DEFAULT (strftime('%s','now'))
            );
        "#)?;
        Ok(std::sync::Arc::new(Self { conn: Mutex::new(conn) }))
    }

    pub fn add(&self, body: String) -> Result<i64, DbError> {
        let c = self.conn.lock().unwrap();
        c.execute("INSERT INTO notes(body) VALUES(?1)", params![body])?;
        Ok(c.last_insert_rowid())
    }

    pub fn all(&self) -> Result<Vec<String>, DbError> {
        let c = self.conn.lock().unwrap();
        let mut st = c.prepare("SELECT body FROM notes ORDER BY id DESC")?;
        let rows = st.query_map([], |r| r.get::<_, String>(0))?
            .filter_map(|r| r.ok()).collect();
        Ok(rows)
    }
}

Сборка под Android

Bundled-SQLite внутри rusqlite требует C-компилятора для cross-target. cargo-ndk уже подсовывает clang из NDK, поэтому всё работает без дополнительных шагов: 

cargo ndk -t arm64-v8a -o app/src/main/jniLibs build --release

Path на Android

// в Kotlin
val dbPath = File(filesDir, "notes.db").absolutePath
val notes = Notes.open(dbPath)
notes.add("first")
val all = notes.all()       // List<String>

Эмуляция миграций

Бонус: добавьте WAL-режим PRAGMA journal_mode = WAL — на Android это даёт надёжность при kill-9 от системы и concurrent-readers.
