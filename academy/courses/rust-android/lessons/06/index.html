Структуры, enum-ы, pattern matching

Это «алгебра» Rust: struct'ы — продукт типов (всё одновременно), enum'ы — сумма типов (один из вариантов). Вместе с pattern matching они дают выразительный способ моделировать предметную область — например, состояния экрана или результат сетевого запроса.

Struct

Enum с данными

Enum в Rust куда мощнее, чем в Java/Kotlin: каждый вариант может нести собственный набор полей. Это позволяет элегантно описать состояние экрана: Loading, Success(data), Error(msg).

Pattern matching и if let

if let — синтаксический сахар, когда вас интересует ровно один вариант. while let крутится, пока шаблон совпадает (удобно при выкачивании из Option<T>-итераторов).
