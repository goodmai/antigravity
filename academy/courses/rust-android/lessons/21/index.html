CI/CD, AGP и публикация в Play Store

Финальный урок курса — про то, как «обмануть» себя в будущем, автоматизировав всё: сборку .so, прогон тестов, подпись AAB и заливку в Play Console. Мы используем GitHub Actions, потому что у Android Build Tools нет официального Docker-образа от Google, но есть превосходные community-actions.

Структура workflow

# .github/workflows/release.yml
name: release
on:
  push:
    tags: ['v*']
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with: { distribution: temurin, java-version: '21' }
      - uses: dtolnay/rust-toolchain@stable
        with:
          targets: aarch64-linux-android,armv7-linux-androideabi,x86_64-linux-android
      - uses: nttld/setup-ndk@v1
        with: { ndk-version: r26d }
      - run: cargo install --locked cargo-ndk
      - run: cargo audit
      - run: cargo test --workspace
      - run: cargo ndk -t arm64-v8a -t armeabi-v7a -t x86_64 \
              -o app/src/main/jniLibs build --release
      - run: ./gradlew bundleRelease
      - uses: r0adkll/upload-google-play@v1
        with:
          serviceAccountJsonPlainText: ${{ secrets.PLAY_JSON }}
          packageName: io.daskibo.password
          releaseFiles: app/build/outputs/bundle/release/app-release.aab
          track: internal

AGP-интеграция: rust-android-gradle

Если вам не нужен ручной cargo ndk, подключите плагин Mozilla — он зарегистрирует Gradle-task cargoBuild, который запустит cargo для всех ABI'ев в нужный момент. 

// build.gradle.kts (project-level)
plugins {
  id("org.mozilla.rust-android-gradle.rust-android") version "0.9.4" apply false
}

// app/build.gradle.kts
plugins {
  id("com.android.application")
  id("org.mozilla.rust-android-gradle.rust-android")
}

cargo {
    module  = "../rust-core"
    libname = "daskibo"
    targets = listOf("arm64", "x86_64", "arm")
    profile = "release"
}

android {
    applicationVariants.all {
        val variant = this
        tasks.named("merge${variant.name.capitalize()}JniLibFolders") {
            dependsOn("cargoBuild")
        }
    }
}

AAB vs APK

Play Store с 2021 требует Android App Bundle (AAB). Google автоматически нарежет APK под конкретное устройство, и Pixel 8 скачает только arm64-v8a-вариант — пользователю не достанется лишних 6 МБ .so.
