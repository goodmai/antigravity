Модуль II · Lesson 12

Юнит-тесты, doc-tests, бенчмарки

Тестирование встроено в язык: cargo test компилирует и запускает все #[test]-функции, doc-test-блоки в комментариях и integration-тесты из tests/. Когда Rust-ядро линкуется в Android — все эти тесты вы прогоняете на host'е до сборки APK, поэтому 80% багов ловятся за секунды на CI.

Юнит-тест

// src/lib.rs
pub fn classify(api: u32) -> &'static str {
    match api { 0..=20 => "old", _ => "modern" }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn old_apis() { assert_eq!(classify(15), "old"); }

    #[test]
    fn modern_apis() { assert_eq!(classify(34), "modern"); }
}

cargo test classify::old запустит только нужный тест, cargo test -- --nocapture покажет println!.

Test внутри playground

Playground умеет в cargo test-режим: переключите tests: true в payload'е, но для простоты у нас тесты обёрнуты в main.

Doc-tests

Любой ///-комментарий с тройными бэктиками — это рабочий пример, который cargo test --doc скомпилирует и выполнит. Документация всегда «свежая», потому что устаревшие примеры падают на CI. 

/// Удваивает число.
///
/// # Examples
///
/// ```
/// assert_eq!(my_crate::dbl(7), 14);
/// ```
pub fn dbl(x: i32) -> i32 { x * 2 }

Benchmarks

Stable Rust не имеет встроенных #[bench], но есть criterion.rs — де-факто стандарт. На Android criterion можно запустить на устройстве через cargo dinghy.
