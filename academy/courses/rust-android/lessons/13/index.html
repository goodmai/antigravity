Android NDK и Rust-toolchain

Android поддерживает 4 ABI: arm64-v8a, armeabi-v7a, x86_64, x86. Каждой соответствует Rust target: aarch64-linux-android, armv7-linux-androideabi, x86_64-linux-android, i686-linux-android. Чтобы кросс-компилироваться, нужен NDK и линкер из него.

Шаги установки

  1. Android Studio → SDK Manager → SDK Tools → ✅ NDK (Side by side) r26 или новее.
  2. rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android i686-linux-android.
  3. Установите cargo-ndk: cargo install cargo-ndk.
  4. Экспортируйте ANDROID_NDK_HOME=~/Android/Sdk/ndk/26.x.x.

.cargo/config.toml

Чтобы Cargo знал, какой линкер использовать для каждой архитектуры, пропишите конфиг в ~/.cargo/config.toml или в корне проекта: 

[target.aarch64-linux-android]
linker = "$ANDROID_NDK_HOME/toolchains/llvm/prebuilt/linux-x86_64/bin/aarch64-linux-android24-clang"

[target.armv7-linux-androideabi]
linker = "$ANDROID_NDK_HOME/toolchains/llvm/prebuilt/linux-x86_64/bin/armv7a-linux-androideabi24-clang"

[target.x86_64-linux-android]
linker = "$ANDROID_NDK_HOME/toolchains/llvm/prebuilt/linux-x86_64/bin/x86_64-linux-android24-clang"

Число 24 — это minSdk: NDK поставляется с sysroot'ами для разных уровней. Поставьте такой же minSdk в Android-проекте, чтобы не было «undefined symbol».

Сборка одной командой

# cargo-ndk прячет всю boilerplate-ку:
cargo ndk -t arm64-v8a -t armeabi-v7a -t x86_64 -o ./jniLibs build --release

# В результате получим:
# jniLibs/arm64-v8a/librustdroid.so
# jniLibs/armeabi-v7a/librustdroid.so
# jniLibs/x86_64/librustdroid.so

Кросс-аспекты, которые ловят 95% новичков

  • crate-type = ["cdylib"] в Cargo.toml — иначе нет .so.
  • 16 KB page size. С NDK r27+ нужен флаг -Wl,-z,max-page-size=16384, иначе Pixel 8 с Android 15 откажется грузить .so. См. developer.android.com — Page sizes.
  • STL не нужен: Rust сам по себе self-contained, не подтягивайте c++_shared.
  • API level: aarch64-linux-android24-clang ≠ aarch64-linux-android21-clang — следите за совместимостью.

В песочнице ниже — небольшая «check'я» утилита, которая на host'е имитирует выбор линкера: на устройстве вы запустите это уже как .so через JNI (Lesson 14).

Задание: в playground'е расширьте linker_for для riscv64-linux-android — это экспериментальный target, который Google планирует поддержать в NDK r29+.
