Функции, методы и замыкания

Функции — единица кода в Rust. Они объявляются fn, имеют типизированные параметры и явный тип возврата. Возврат пишется без return — последнее выражение функции и есть её значение (если строка не оканчивается точкой с запятой).

Сигнатуры и возврат

Методы и impl

Методы привязываются к типу через блок impl. Первый параметр — &self (read-only), &mut self (mutable) или self (move). Функции без self — это ассоциированные функции; принято new() и подобные конструкторы.

Замыкания на старте

Замыкание (|x| x + 1) — анонимная функция, которая может захватывать значения из окружающего scope. На Android замыкания часто используются как «callback'и» из Rust-ядра, например, для нотификации UI.
