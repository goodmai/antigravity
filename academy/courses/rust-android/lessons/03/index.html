Control flow: if, match, циклы

Управляющие конструкции Rust — это выражения, а не операторы: каждое if и match возвращает значение. Это удаляет целый класс багов вида «забыл вернуть в одной из веток».

if как выражение

match — exhaustive pattern matching

match требует обработать все возможные варианты — иначе компилятор не пропустит код. Для перечислимых enum'ов это даёт гарантию «новая ветка enum'а нигде не забыта», что особенно ценно в больших Rust-ядрах для Android.

loop, while, for

loop — бесконечный, прерывается break; break умеет возвращать значение из loop. for работает поверх любого IntoIterator — массивов, диапазонов, Vec'ов.
