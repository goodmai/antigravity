Hello, World & Cargo

Rust — это компилируемый системный язык без сборщика мусора. Он гарантирует безопасность памяти за счёт правил ownership и borrowing, которые проверяются на этапе компиляции. Программа на Rust компилируется в нативный машинный код — поэтому Rust одинаково хорошо чувствует себя в ядре ОС, в браузерном WebAssembly и внутри Android-приложения через JNI.

Что вам даёт Rust

  • Memory safety без GC — ownership и borrow-checker отлавливают use-after-free, double-free и data race в safe-коде.
  • Zero-cost abstractions — итераторы, generics, trait-объекты компилируются в код, эквивалентный ручному циклу.
  • Errors as values — Result<T, E> и Option<T> делают ошибку частью типа, а не исключения.
  • Один инструмент — cargo собирает, тестирует, бенчит, форматирует, публикует.

Toolchain в одну команду

Устанавливать Rust лучше через rustup — это менеджер toolchain'ов, который умеет переключаться между stable / beta / nightly и устанавливать cross-таргеты (нам понадобится aarch64-linux-android в Модуле III). 

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustup default stable
rustup component add clippy rustfmt
cargo new hello_rust && cd hello_rust
cargo run

Минимальная программа

fn main() — точка входа. println! завершается восклицательным знаком, потому что это макрос, а не функция: он раскрывается в цепочку write! в stdout. Все три макроса assert!, assert_eq!, assert_ne! компилируются в if !(…) { panic!() }, поэтому ваша песочница «сама себя» проверит при запуске.

Форматирование строк

Format-строки Rust похожи на Python f-strings: {name} подставляет переменную по имени, {:?} — debug-репрезентация, {:#?} — pretty-print. Тип сам решает, как форматироваться, через trait'ы Display и Debug.
