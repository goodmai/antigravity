Day 1 · Morning · Lesson 1

Hello, World

Rust is a systems programming language. It compiles directly to machine code, it has no garbage collector, and it uses an ownership system that catches whole categories of memory bugs at compile time. The tradeoff is that the compiler asks a lot of you up front — and gives back fast, predictable, memory-safe programs in return.

What Rust gives you

  • Memory safety without a GC. The ownership and borrow rules guarantee no dangling references, double frees, or data races in safe code.
  • Zero-cost abstractions. Iterators, generics, traits and closures compile down to code as tight as a hand-written loop.
  • Errors as values. Result<T, E> and Option<T> push error-handling into the type system instead of leaving it to exceptions.
  • One tool to rule them all. cargo builds, tests, benchmarks, lints, formats and publishes your crates.

The smallest legal program

Every executable Rust program needs a function called main. The fn keyword introduces it, () is its parameter list, and { … } is its body. println! ends in a bang because it is a macro, not a function — we'll meet macros properly later today.

What just happened

  1. Rust read fn main() and knew this was a binary, not a library.
  2. It evaluated the let binding and gave the name greeting to a string literal.
  3. println! expanded to a chain of write! calls against stdout.
  4. The three assert* macros are compiled into if !(…) { panic!() }. If any of them is false the program crashes with a clear message; otherwise it exits cleanly.

String formatting in one minute

Rust's format strings look like Python f-strings, except that the values are inlined by name (or by position) and the type decides how the value is displayed. {x} uses the variable named x; {:?} asks for the debug representation, useful for collections and custom types.
