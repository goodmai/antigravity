Tuples and Arrays

Tuples and arrays are Rust's two fixed-size compound types. Their length is part of the type — that's why they live on the stack and need no allocator. Tuples group values of potentially different types; arrays group values of one type.

Arrays

An array is written [T; N] — element type T, length N (a compile-time constant). All elements have the same type, and the length is fixed forever.

Tuples

A tuple is an ad-hoc bundle written (a, b, c). Access individual fields by index with dot syntax: t.0, t.1, …. The empty tuple () is the unit type — used as the return value of functions that "don't return anything".

Array iteration

for x in arr consumes the array (moves the elements out); for x in &arr iterates by shared reference; for x in &mut arr iterates by exclusive reference and lets you mutate in place. Combine with .iter().enumerate() to also get the index.

Patterns and destructuring

Tuples and arrays can be unpacked anywhere a pattern is expected — on the left of let, in match arms, in function parameters. Use _ to ignore a position and .. to ignore a span.

Exercise: transpose a 3×3 matrix

Implement transpose for a 3×3 array so that transpose(m)[i][j] == m[j][i]. Fixed sizes mean you don't need any heap allocation.
