User-Defined Types

Now we build our own types. Rust has three flavours: named structs (records with field names), tuple structs (positional records), and enums (sum types — a value is one of several variants). Together with type aliases and constants they cover almost everything you'll want to model.

Named structs

Tuple structs

When the field names would add no information, a tuple struct is more compact. The newtype pattern (a one-field tuple struct) is the standard way to attach extra meaning to a primitive — e.g. distinguishing a UserId from a plain u64.

Enums

An enum (a.k.a. tagged union, sum type) describes a value that is one of several variants. Each variant can carry its own payload. The compiler forces every match on the enum to handle every variant.

Type aliases, const, static

type Foo = Bar; creates an alias — same type, new name — useful for shortening verbose generic types. const introduces a compile-time constant inlined at every use site; static introduces a single fixed memory location that lives for the entire program.
