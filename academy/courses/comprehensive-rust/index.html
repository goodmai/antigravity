Comprehensive Rust 🦀

A four-day deep dive into Rust — from your first fn main() all the way to ownership, traits, generics, lifetimes, iterators, error handling and unsafe code. Every lesson ships with an editable Rust Playground cell pre-loaded with assert! / assert_eq! calls so you can verify your understanding by running the code in the browser.

How to use this course. Read each page, then run the playground cell. If all assertions pass, the cell turns green; if you break something, you get a red error from the Rust compiler. Edit freely — there is no "wrong" way to experiment.
