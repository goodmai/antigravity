△ Архитектура децентрализованного приложения

Курс учит проектировать, а не зубрить стек. Один и тот же продукт — «маркетплейс цифровых работ + лента + платежи» — строится тремя способами по неизменной сетке из 9 «кирпичей», чтобы архитектурные решения принимались сравнением trade-off, а не по моде.

Символ курса — масонский циркуль △: один домен мы трижды «обводим вокруг центра» — классикой, облаком Google и децентрализацией. plan.md · README.md.
Сравнение, а не вера. Для каждого кирпича — trade-off: стоимость, латентность, доверие, суверенитет данных, операционная сложность, vendor lock-in. Финал — осознанный гибрид, а не «всё на блокчейне».
