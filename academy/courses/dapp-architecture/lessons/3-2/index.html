Децентрализованный compute

Канон: Akash SDL, Fluence docs.

Аналог кирпича Compute (Cloud Run/GKE): рынок вычислений, где ноды — анонимные провайдеры.

Модель Akash

# deploy.yaml (SDL) — упрощённо
services:
  web: { image: myorg/marketplace:1.0, expose: [{ port: 8080, to: [{global: true}] }] }
profiles:
  compute: { web: { resources: { cpu: 0.5, memory: 512Mi } } }
# деплой → ставки провайдеров (reverse auction) → escrow оплата в AKT
Цена и доверие. Дешевле облака, но провайдер ноды недоверенный: нужны воспроизводимые образы, шифрование данных в покое и отсутствие секретов внутри контейнера.
Артефакт урока. ADR-04 «compute»: Cloud Run vs Akash (цена/доверие/SLA).
