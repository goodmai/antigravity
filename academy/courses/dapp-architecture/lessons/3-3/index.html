Блокчейн как backend

Канон: Ethereum dev docs, EIP-1559.

Блокчейн — это не «база», а детерминированный реплицируемый application-слой с дорогим состоянием и публичным исполнением.

  • Детерминизм: никакого random/времени — все ноды должны прийти к тому же состоянию.
  • Газ: вычисление и хранение стоят денег; EIP-1559 — base fee (сжигается) + tip.
  • Аккаунты: EOA (ключ) и контрактные.
// контракт = публичная, неизменяемая бизнес-логика
function purchase(uint256 workId) external payable {
    require(msg.value == price[workId], "bad price");
    owner[workId] = msg.sender;          // состояние = дорогое
    emit Purchased(workId, msg.sender);  // событие = дешёвый индекс
}
