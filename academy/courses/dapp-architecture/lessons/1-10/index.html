Масштаб и отказоустойчивость

Канон: CAP / PACELC (Abadi), Release It! (паттерны устойчивости).

Масштаб — это не «добавить серверов», а осознанный выбор между согласованностью и доступностью.

CAP → PACELC

При сетевом разделении (P) выбираем между согласованностью и доступностью. Else (нормальная работа) — компромисс латентности и согласованности. Для денег — C, для ленты — A/латентность.

Устойчивость к отказам

  • Timeout + retry с jitter — но только для идемпотентных операций.
  • Circuit breaker — не добивать упавшую зависимость.
  • Backpressure — отвергать нагрузку явно, а не падать.
  • Graceful degradation — лента без рекомендаций лучше, чем 500.
