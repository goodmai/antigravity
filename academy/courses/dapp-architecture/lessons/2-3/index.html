Данные на Google Cloud

Канон: Spanner docs, Firestore docs.

Тот же кирпич State/Data, но выбор — между управляемыми движками с разной моделью согласованности и масштаба.

СервисМодельСильная сторона
Cloud SQLmanaged Postgres/MySQLмиграция «как есть»
AlloyDBPostgres-совместимый, HTAPаналитика+OLTP
Spannerглобальный, strong consistencyгоризонтальный масштаб + ACID
Firestoreдокументный, real-timeмобильный/web sync
Trade-off. Spanner снимает потолок масштаба, но это сильнейший lock-in модуля. Cloud SQL — почти без lock-in, но потолок обычного Postgres.
