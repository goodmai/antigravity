Состояние и данные: реляционка

Канон: PostgreSQL docs, DDIA (Kleppmann), гл. 7.

Реляционная БД даёт ACID и сильные инварианты. По умолчанию начинайте с PostgreSQL — это «истина» системы.

Транзакции и изоляция

Уровень изоляции определяет, какие аномалии возможны. Для денежных операций — как минимум REPEATABLE READ, а инварианты баланса защищаются ограничениями БД, не кодом приложения.

Миграции expand-contract

-- 1. EXPAND: добавить nullable-колонку, деплой кода, читающего обе формы
ALTER TABLE orders ADD COLUMN total_cents bigint;
-- 2. BACKFILL: перенести данные пачками
-- 3. CONTRACT: сделать NOT NULL, убрать старую колонку
ALTER TABLE orders ALTER COLUMN total_cents SET NOT NULL;

Так схема меняется без даунтайма и совместима со старым и новым кодом одновременно.

Индексы. Индекс ускоряет чтение и замедляет запись. Индексируйте под реальные запросы (EXPLAIN ANALYZE), а не «на всякий случай».
