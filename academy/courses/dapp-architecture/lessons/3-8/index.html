Данные и сообщения p2p

Канон: libp2p docs, Ceramic docs.

Аналог кирпича Messaging/изменяемых данных (Pub/Sub, Firestore) без сервера: peer-to-peer + CRDT для конфликт-free слияния.

  • libp2p pubsub — транспорт сообщений между пирами.
  • OrbitDB / Ceramic — изменяемые «потоки» поверх IPFS.
  • CRDT — конкурентные правки сходятся без координатора.
Граница. Хорошо для социального графа/комментариев (eventual ок), плохо для денежных инвариантов — там нужна строгая согласованность из урока 3.3.
