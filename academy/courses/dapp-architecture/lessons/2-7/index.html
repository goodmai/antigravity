Модуль 2 — Облачный Google подход · Урок 2.7 · VPC

Сеть и периметр

Канон: Cloud Load Balancing, Cloud Armor.

Кирпич Networking: глобальный L7-балансировщик, WAF и API-шлюз как управляемые сервисы.

  • Global HTTP(S) LB — единый anycast-вход, авто-TLS.
  • Cloud Armor — WAF, гео/IP-правила, защита от DDoS.
  • Serverless VPC Access — Cloud Run в приватную сеть.
  • Apigee / API Gateway — квоты, ключи, монетизация API.
Принцип. Периметр — это политика, а не файрвол: правила Cloud Armor версионируются как код вместе с IaC.
