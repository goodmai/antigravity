Секреты и ключи

Канон: Secret Manager, Cloud KMS.

Кирпич Secrets/Keys в Google: разделяем секреты (Secret Manager) и ключи шифрования (Cloud KMS).

  • Версионирование секрета + автоматическая ротация.
  • CMEK — ваш ключ в KMS шифрует данные сервисов.
  • Доступ — через IAM-роль ворклоада, не через скачанный файл.
  • Аудит обращений к секрету — в Cloud Logging.
Trade-off. KMS снимает заботу о HSM, но ключи всё ещё в периметре провайдера. Сравните это с самокастодиальной моделью из урока 3.10.
