Identity на Google Cloud

Канон: Cloud IAM overview, Workload Identity Federation.

Два разных IAM: пользователи продукта (Identity Platform / Firebase Auth) и сервисы (Cloud IAM роли).

Workload Identity Federation

Главная идея безопасности модуля: никаких долгоживущих service-account ключей. CI/CD и внешние ворклоады получают короткоживущий токен по федерации (OIDC), а не JSON-файл.

GitHub Actions (OIDC) ─▶ STS обмен ─▶ временный GCP-токен ─▶ деплой
                          (нет хранимого секрета)
