Децентрализованная идентичность

Канон: EIP-4361 (SIWE), W3C DID Core.

Аналог кирпича Identity (OIDC/Cloud IAM). Идентичность = контроль приватного ключа; нет центрального IdP.

Sign-In with Ethereum

1. сервер → nonce
2. кошелёк подписывает структурированное сообщение (домен+nonce)
3. сервер проверяет подпись → сессия
   (нет пароля, нет хранилища учёток, нельзя «забыть пароль»)
Цена модели. Нет «восстановления доступа»: потеря ключа = потеря аккаунта. DID/VC добавляют атрибуты («верифицированный автор») без раскрытия личности.
Артефакт урока. Auth-поток на кошельке (SIWE) + сравнение с OIDC из 1.8.
