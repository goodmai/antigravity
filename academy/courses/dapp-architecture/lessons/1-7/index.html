Файлы и медиа

Канон: AWS S3 presigned URLs, MDN: HTTP caching.

Файлы не хранят в БД и не гоняют через бэкенд. Объектное хранилище + presigned URL + CDN — индустриальный паттерн.

Прямая загрузка через presigned URL

client → POST /uploads        (бэкенд выдаёт presigned PUT URL)
client → PUT  s3://bucket/... (грузит напрямую, минуя бэкенд)
client → POST /uploads/confirm (бэкенд валидирует, пишет метаданные)

Бэкенд не пропускает через себя гигабайты — он только авторизует и фиксирует метаданные.

Доставка через CDN

  • Иммутабельные ассеты — Cache-Control: max-age=31536000, immutable.
  • Версионирование через хэш в имени файла, а не query-параметр.
  • Приватный контент — короткоживущие подписанные ссылки.
