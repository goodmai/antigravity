Аналитика и события

Канон: Pub/Sub docs, BigQuery docs.

Кирпич Messaging в Google — это управляемый Pub/Sub + аналитический сток в BigQuery.

Event-driven serverless

Cloud Run ──publish──▶ Pub/Sub topic
                         ├─ push → Cloud Run (обработчик)
                         └─ BigQuery subscription → аналитика SQL
  • Pub/Sub — at-least-once; обработчик так же обязан быть идемпотентным.
  • Eventarc маршрутизирует события сервисов (например, объект в Storage).
  • BigQuery — сток для продуктовой аналитики, не операционная БД.
