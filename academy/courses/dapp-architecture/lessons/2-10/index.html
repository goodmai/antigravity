Доставка и IaC

Канон: Cloud Deploy, Config Connector.

Кирпич Delivery: build once → promote many по средам, инфраструктура — декларативный код.

Cloud Build → Artifact Registry (один образ + provenance)
            → Cloud Deploy: dev → staging → prod (одобрение между)
Terraform / Config Connector: инфраструктура из git, drift виден в PR
Принцип. Образ собирается один раз и продвигается неизменным. Пересборка под прод — источник «works on staging» багов.
Артефакт урока. Pipeline-диаграмма: Cloud Build → Deploy (dev→prod) + IaC.
