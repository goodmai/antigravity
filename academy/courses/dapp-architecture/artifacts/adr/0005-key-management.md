# ADR-0005: Управление ключами

- **Статус:** proposed
- **Дата:** YYYY-MM-DD
- **Решает:** кирпич Secrets/Keys · урок 3.10 (vs 2.8 KMS)

## Контекст

Кому принадлежит ключ, как восстановить доступ, кто может отозвать.
Сравниваем провайдерскую модель (Cloud KMS) с самокастодиальной.

## Рассмотренные варианты

| Вариант | Суверенитет | Восстановление | Отзыв | Сложность |
|---|---|---|---|---|
| Cloud KMS / Secret Manager | у провайдера | через IAM | мгновенный | низкая |
| MPC-кошелёк | разделён (порог) | пороговое | сложнее | средняя |
| ERC-4337 (AA) | у пользователя | social recovery | контрактный | выше |

## Решение

<Заполнить. Подсказка: разделить «секреты сервиса» (KMS) и «ключ
аккаунта пользователя» (AA/MPC) — это разные кирпичи с разным владельцем
риска.>

## Последствия

- Threat-model: потеря ключа, скомпрометированный guardian, сговор MPC-долей.
- UX-цена самокастодиала: нет «забыл пароль».
