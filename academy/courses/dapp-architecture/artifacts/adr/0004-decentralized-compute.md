# ADR-0004: Децентрализованный compute

- **Статус:** proposed
- **Дата:** YYYY-MM-DD
- **Решает:** кирпич Compute (децентрализация) · урок 3.2

## Контекст

Часть нагрузки можно вынести на рынок вычислений (Akash/Fluence/Golem).
Провайдер ноды — недоверенный. Сравниваем с Cloud Run (ADR-0003).

## Рассмотренные варианты

| Вариант | Цена | Доверие к исполнителю | SLA |
|---|---|---|---|
| Cloud Run (база) | выше | провайдер доверенный | управляемый |
| Akash | ниже | нода анонимна | нет жёсткого SLA |
| Fluence/Golem | ниже | зависит от модели | нет |

## Решение

<Заполнить. Подсказка: hot-path с SLA — облако; батч/stateless без
секретов — Akash. Требования: воспроизводимый образ, шифрование данных
в покое, отсутствие секретов в контейнере.>
