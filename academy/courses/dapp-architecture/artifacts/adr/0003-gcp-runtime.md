# ADR-0003: Runtime на Google Cloud

- **Статус:** proposed
- **Дата:** YYYY-MM-DD
- **Решает:** кирпич Compute (Google) · урок 2.2

## Контекст

Тот же сервис на managed-first Google Cloud. Профиль нагрузки:
неравномерный трафик, периоды простоя, потребность в scale-to-zero.

## Рассмотренные варианты

| Вариант | Когда выигрывает | Контроль | Lock-in |
|---|---|---|---|
| Cloud Functions | событие → короткая функция | мин. | средний |
| Cloud Run | stateless-контейнер, scale-to-zero | баланс | низкий (контейнер) |
| GKE Autopilot | нужен k8s API без нод | выше | средний |
| GKE Standard | тонкий тюнинг/GPU | макс. | средний |
