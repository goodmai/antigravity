**open education + an AI/agent‑economy public good** — maps cleanly onto most ecosystem
mandates, which improves fit.

## How to use this matrix

1. **Sequence by model.** Apply to **retroactive** programs (Base, Optimism RetroPGF) *after*
   shipping the testnet dApp; apply to **forward‑looking** programs (Arbitrum, BNB, Celo,
   Polygon, Avalanche) once the [Roadmap](./roadmap.md) Phase 1 deliverables exist.
2. **Lead with the public‑good narrative.** Open education + AI/agent‑economy infrastructure is
   eligible across the board; Celo's Frontier Pool and Arbitrum's AI track are the sharpest fits.
3. **Reuse the data room.** The [pitch‑deck epic](./epics/EPIC-02-pitch-deck.md) produces the
   deck, one‑pager, and metrics every application asks for.
4. **Multi‑chain deploys = multiple eligibilities.** Phase 2 deploys to Arbitrum/OP/Base/BNB
   testnets, each of which unlocks its own grant track.

## Application checklist (common across programs)

- [ ] Whitepaper + Yellowpaper links (this repo's `docs/`)
- [ ] Public roadmap with milestones (`roadmap.md`)
- [ ] Live testnet deployment + verified contracts (EPIC‑01 Phase 2)
- [ ] Open‑source repo + license
- [ ] Team / contributors and prior traction (academy usage metrics)
- [ ] Budget broken down by milestone
- [ ] KYC/KYB readiness (required by Scroll > $2K, common elsewhere)
