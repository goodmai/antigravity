# Лаба 26: Развёртывание среды: ПК и мобильные

Воспроизводимая установка и верификация окружения CLI и понимание мобильной песочницы.

## 🎯 Цель

Закрепить материал Урока 26 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- Google Cloud Shell — `https://shell.cloud.google.com` → `git clone`
- Replit — *Create Repl → Import from GitHub*

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash
# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh
```

## 📋 Задачи

### Задача 1 — Установка CLI

**Цель:** Поставить инструмент.

**Шаги:**
1. Установи Node + CLI в песочнице.

**Критерий приёмки:** `--version` отдаёт версию.

### Задача 2 — Верификация PATH

**Цель:** Проверить путь.

**Шаги:**
1. `which`/`command -v`.

**Критерий приёмки:** Бинарь в $PATH, путь зафиксирован.

### Задача 3 — Авторизация

**Цель:** Пройти login.

**Шаги:**
1. Инициируй OAuth-флоу.

**Критерий приёмки:** Сессия активна.

### Задача 4 — Первый запрос

**Цель:** Проверить связь.

**Шаги:**
1. Отправь тестовый запрос.

**Критерий приёмки:** Получен ответ — сеть ок.

### Задача 5 — Сравнение сред

**Цель:** CLI vs мобильная.

**Шаги:**
1. Таблица: контроль, доступ к ФС, изоляция.

**Критерий приёмки:** Различия описаны корректно.

### Задача 6 — Воспроизводимость

**Цель:** Скриптовать setup.

**Шаги:**
1. `setup.sh`, который ставит всё с нуля.

**Критерий приёмки:** Чистый прогон скрипта успешен.

### Задача 7 — Диагностика установки

**Цель:** Починить сбой.

**Шаги:**
1. Сломай PATH, восстанови.

**Критерий приёмки:** Причина найдена и устранена.
