Навигация, изменение и безопасный рефактор в большом репозитории.

## 🎯 Цель

Закрепить материал Урока 24 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- github.dev — открой репозиторий и нажми клавишу **`.`**
- Google Cloud Shell — `https://shell.cloud.google.com` → `git clone`

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash
# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh
```

## 📋 Задачи

### Задача 1 — Карта репозитория

**Цель:** Построить обзор.

**Шаги:**
1. Агент строит `notes/repo-map.md` (модули, точки входа).

**Критерий приёмки:** Карта отражает реальную структуру.

### Задача 2 — Поиск по символам

**Цель:** Найти определение/использования.

**Шаги:**
1. Локализуй ключевую функцию и её вызовы.

**Критерий приёмки:** Найдены все использования.

### Задача 3 — Изолированное изменение

**Цель:** Малый безопасный патч.

**Шаги:**
1. Точечная правка через @file/@symbol.

**Критерий приёмки:** Затронут минимум файлов.

### Задача 4 — Влияние изменения

**Цель:** Оценить blast radius.

**Шаги:**
1. Список затронутых модулей до правки.

**Критерий приёмки:** Оценка совпала с фактом.

### Задача 5 — Большой рефактор

**Цель:** Поэтапно и под тестами.

**Шаги:**
1. Сквозное переименование через Turbo + diff.

**Критерий приёмки:** Все тесты зелёные, есть откат.

### Задача 6 — Производительность контекста

**Цель:** Не перегружать агента.

**Шаги:**
1. Работай срезами, а не всем репо.

**Критерий приёмки:** Задача решена без переполнения контекста.

### Задача 7 — Онбординг-документ

**Цель:** Сделать артефакт.

**Шаги:**
1. `ONBOARDING.md` для нового разработчика.

**Критерий приёмки:** Новичок может стартовать по документу.
