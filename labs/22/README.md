# Лаба 22: Свой MCP-сервер с нуля

> 🔗 Практика к [Уроку 22](../../lessons/22/README.md) — *Кастомные MCP-серверы с нуля*

Пишем собственный MCP-сервер и подключаем его к агенту.

## 🎯 Цель

Закрепить материал Урока 22 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- Replit — *Create Repl → Import from GitHub*
- Google Cloud Shell — `https://shell.cloud.google.com` → `git clone`

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash
# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh
```

## 📋 Задачи

### Задача 1 — Каркас сервера

**Цель:** Инициализировать проект.

**Шаги:**
1. FastMCP/SDK: пустой сервер, запуск.

**Критерий приёмки:** Сервер стартует и хендшейкит.

### Задача 2 — Первый tool

**Цель:** Добавить инструмент.

**Шаги:**
1. Tool с входной схемой и валидацией.

**Критерий приёмки:** Tool вызывается агентом, схема проверяется.

### Задача 3 — Ресурс

**Цель:** Отдать данные как resource.

**Шаги:**
1. Зарегистрируй ресурс.

**Критерий приёмки:** Ресурс читается агентом.

### Задача 4 — Ошибки

**Цель:** Корректная обработка.

**Шаги:**
1. Верни структурную ошибку на плохой ввод.

**Критерий приёмки:** Агент получает понятную ошибку, не падает.

### Задача 5 — Подключение

**Цель:** Зарегистрировать в агенте.

**Шаги:**
1. Пропиши в конфиг MCP.

**Критерий приёмки:** Инструменты сервера видны.

### Задача 6 — Безопасность

**Цель:** Ограничить возможности.

**Шаги:**
1. Валидация ввода, least privilege.

**Критерий приёмки:** Опасный ввод отклоняется.

### Задача 7 — Тест и доки

**Цель:** Покрыть и описать.

**Шаги:**
1. Тест tool + README с примером.

**Критерий приёмки:** Тесты зелёные, есть пример вызова.
