# Лабораторная работа 34: Агентная разработка с Android CLI

В этой лабораторной работе мы освоим использование Android CLI для автоматизации типичных задач мобильной разработки.

## Предварительные требования
1. Установленный `android-cli` версии 1.0+.
2. Открытая Android Studio с тестовым проектом (для команд `android studio *`).

---

## Задание 1: Проверка окружения
Убедитесь, что CLI корректно установлен и видит Android Studio.

**Команда:**
```bash
android studio check
```

**Критерий успеха:** Вывод подтверждает активное соединение с IDE.

---

## Задание 2: Семантический поиск
Найдите декларацию главного Activity вашего приложения, не открывая IDE вручную.

**Команда:**
```bash
android studio find-declaration MainActivity
```

**Критерий успеха:** Вы получили полный путь к файлу и номер строки с определением класса.

---

## Задание 3: Анализ качества кода
Запустите глубокую проверку файла на соответствие стандартам Android Lint и Compose Best Practices.

**Команда:**
```bash
android studio analyze-file <путь_к_вашему_файлу.kt>
```

**Критерий успеха:** Список предупреждений (если они есть) выведен в терминал в структурированном виде.

---

## Задание 4: Рендеринг интерфейса
Сгенерируйте изображение превью для Jetpack Compose компонента.

**Команда:**
```bash
android studio render-compose-preview
```

**Критерий успеха:** Путь к сгенерированному PNG-файлу отображен в выводе. Посмотрите изображение, чтобы убедиться в корректности рендера.

---

## Задание 5: Установка специализированного навыка
Добавьте в окружение агента навык для работы с CameraX.

**Команда:**
```bash
android skills add --skill="CameraX migration"
```

**Критерий успеха:** Навык добавлен в список доступных (`android skills list`).
