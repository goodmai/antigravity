# Лабораторная работа 33: Миграция и настройка MCP Setup

В этой лабораторной работе мы на практике пройдем путь миграции со старого CLI на новый и настроим интеграцию с внешними сервисами через MCP.

## Предварительные требования
1. Установленный `gemini-cli` (команда `gemini`).
2. Установленный `agy` CLI.
3. Доступ к терминалу.

---

## Задание 1: Запуск миграции
Запустите команду миграции, которая перенесет ваши настройки в новую экосистему Antigravity.

**Команда:**
```bash
gemini -agy
```

**Критерий успеха:** В директории `~/.gemini/config/` появился файл `mcp_config.json`.

---

## Задание 2: Настройка MCP сервера "Fetch"
Добавьте в `mcp_config.json` сервер для получения содержимого веб-страниц.

1. Откройте `~/.gemini/config/mcp_config.json`.
2. Добавьте в объект `mcpServers` следующую запись:

```json
"fetch": {
  "command": "uvx",
  "args": ["mcp-server-fetch"]
}
```

**Критерий успеха:** При запуске `agy` и вводе команды `/tools` вы видите инструмент `fetch`.

---

## Задание 3: Глобальная установка Skill
Установите новый скилл и сделайте его доступным для всех инструментов Antigravity (IDE и CLI).

1. Установите скилл (замените URL на реальный или используйте заглушку):
   ```bash
   npx skills add https://github.com/google/gemini-cli-skills/tree/main/skills/hello-world -y -g
   ```
2. Переместите его в общую директорию:
   ```bash
   mkdir -p ~/.gemini/skills
   mv ~/.agents/skills/hello-world ~/.gemini/skills/
   ```

**Критерий успеха:** Скилл отображается в списке при вызове `/skills` в `agy`.

---

## Задание 4: Проверка работоспособности
Запустите `agy` и попросите его проанализировать любую статью в интернете, используя установленный сервер `fetch`.

**Пример промпта:**
```bash
agy --prompt "Summarize https://example.com using fetch tool"
```

**Критерий успеха:** Агент успешно вызвал инструмент `fetch` и выдал суммаризацию.
