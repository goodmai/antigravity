## 📋 Задачи

### Задача 1 — Что такое MCP

**Цель:** Зафиксировать модель протокола.

**Шаги:**
1. `notes/mcp.md`: транспорт, инструменты, ресурсы.

**Критерий приёмки:** Описаны 3 ключевых понятия MCP.

### Задача 2 — Подключить сервер

**Цель:** Добавить готовый MCP.

**Шаги:**
1. Подключи filesystem/postgres MCP.

**Критерий приёмки:** Инструменты сервера видны агенту.

### Задача 3 — Вызов инструмента

**Цель:** Использовать MCP-tool.

**Шаги:**
1. Через MCP выполни операцию (запрос/чтение).

**Критерий приёмки:** Результат получен через MCP, не напрямую.

### Задача 4 — Скоупы и безопасность

**Цель:** Ограничить доступ.

**Шаги:**
1. Сузь права MCP до минимума.

**Критерий приёмки:** Доступ ограничен принципом least privilege.

### Задача 5 — Несколько серверов

**Цель:** Скомбинировать MCP.

**Шаги:**
1. Подключи 2 сервера, реши задачу с обоими.

**Критерий приёмки:** Задача решена связкой серверов.

### Задача 6 — Диагностика MCP

**Цель:** Отладить сбой подключения.

**Шаги:**
1. Сломай конфиг, найди и почини.

**Критерий приёмки:** Причина сбоя локализована по логам.

### Задача 7 — Документация интеграции

**Цель:** Описать схему.

**Шаги:**
1. `notes/mcp.md`: диаграмма подключений.

**Критерий приёмки:** Схема отражает реальную конфигурацию.
