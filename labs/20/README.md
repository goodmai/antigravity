# Лаба 20: Промпт-инжиниринг для агентов

> 🔗 Практика к [Уроку 20](../../lessons/20/README.md) — *Промпт-инжиниринг для агентов*

Системная техника промптов для агентных задач: роль, контекст, формат, ограничения.

## 🎯 Цель

Закрепить материал Урока 20 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** github.dev — лёгкий редактор без терминала — для задач без запуска кода.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- github.dev — открой репозиторий и нажми клавишу **`.`**
- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- Replit — *Create Repl → Import from GitHub*

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash
# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh
```

## 📋 Задачи

### Задача 1 — Структура промпта

**Цель:** Освоить каркас.

**Шаги:**
1. `prompts/structure.md`: Роль/Задача/Контекст/Формат.

**Критерий приёмки:** Шаблон применим к любой задаче.

### Задача 2 — До/после

**Цель:** Сравнить слабый и сильный промпт.

**Шаги:**
1. 2 версии одной задачи, сравни выходы.

**Критерий приёмки:** Сильный промпт даёт стабильнее результат.

### Задача 3 — Ограничения

**Цель:** Задать рамки.

**Шаги:**
1. Добавь явные DO/DON'T.

**Критерий приёмки:** Агент соблюдает ограничения.

### Задача 4 — Few-shot

**Цель:** Привести примеры.

**Шаги:**
1. Добавь 2 примера ввод→вывод.

**Критерий приёмки:** Формат вывода стабилизирован.

### Задача 5 — Декомпозиция

**Цель:** Разбить сложный промпт.

**Шаги:**
1. Цепочка под-промптов.

**Критерий приёмки:** Каждый шаг проверяем отдельно.

### Задача 6 — Анти-инъекции

**Цель:** Защитить промпт.

**Шаги:**
1. Опиши, как отделять данные от инструкций.

**Критерий приёмки:** Внешний текст не переопределяет инструкции.

### Задача 7 — Библиотека промптов

**Цель:** Собрать переиспользуемое.

**Шаги:**
1. `prompts/` с 5 шаблонами под задачи курса.

**Критерий приёмки:** Шаблоны документированы и применимы.
