# Лаба 06: Самоисцеляющийся воркфлоу

## 🎯 Цель

Закрепить материал Урока 6 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`

## 📋 Задачи

### Задача 1 — Падающий пайплайн

**Цель:** Подготовить дефект.

**Шаги:**
1. Сломай тест намеренно.

**Критерий приёмки:** CI/тест красный.

### Задача 2 — Детектор

**Цель:** Научить агента ловить падение.

**Шаги:**
1. Workflow читает лог ошибки.

**Критерий приёмки:** Причина извлечена из лога.

### Задача 3 — Авто-фикс

**Цель:** Сгенерировать исправление.

**Шаги:**
1. Агент правит код по логу.

**Критерий приёмки:** Тест зелёный после авто-фикса.

### Задача 4 — Цикл повтора

**Цель:** Зациклить до успеха с лимитом.

**Шаги:**
1. Не более 5 попыток, затем стоп.

**Критерий приёмки:** Лимит соблюдается, нет бесконечного цикла.

### Задача 5 — Эскалация

**Цель:** Обработать неустранимое.

**Шаги:**
1. При исчерпании попыток — отчёт человеку.

**Критерий приёмки:** Формируется внятный отчёт об эскалации.

### Задача 6 — Идемпотентный прогон

**Цель:** Безопасный повтор.

**Шаги:**
1. Повторный запуск на зелёном проекте.

**Критерий приёмки:** Ничего не ломается, no-op.

### Задача 7 — Метрики

**Цель:** Измерить эффективность.

**Шаги:**
1. Логируй MTTR (время до зелёного).

**Критерий приёмки:** Есть числовой показатель самоисцеления.
