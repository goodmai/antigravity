## 🎯 Цель

Закрепить материал Урока 17 через 7 практических задач в облачной

считается сданной, когда выполнен финальный чек-лист.

## 📋 Задачи

### Задача 1 — Каркас Next

**Цель:** Поднять приложение.

**Шаги:**
1. `create-next-app` (App Router, TS, Tailwind).

**Критерий приёмки:** Dev-сервер отдаёт стартовую страницу.

### Задача 2 — Компонент карточки

**Цель:** Сгенерировать UI.

**Шаги:**
1. Агент: ProductCard на Tailwind, hover-анимация.

**Критерий приёмки:** Карточка адаптивна и доступна (a11y).

### Задача 3 — Серверный компонент

**Цель:** Данные на сервере.

**Шаги:**
1. Server Component с фетчем.

**Критерий приёмки:** Данные приходят без клиентского запроса.

### Задача 4 — API route

**Цель:** Добавить эндпоинт.

**Шаги:**
1. `/api/products` возвращает JSON.

**Критерий приёмки:** Эндпоинт отвечает 200 с данными.

### Задача 5 — Hydration error

**Цель:** Воспроизвести и починить.

**Шаги:**
1. Создай расхождение SSR/CSR, исправь по подсказке агента.

**Критерий приёмки:** Предупреждение hydration исчезло.

### Задача 6 — Загрузка/ошибки

**Цель:** Состояния UI.

**Шаги:**
1. `loading.tsx` и `error.tsx`.

**Критерий приёмки:** Состояния отображаются корректно.

### Задача 7 — Сборка прод

**Цель:** Проверить билд.

**Шаги:**
1. `next build`.

**Критерий приёмки:** Прод-сборка без ошибок типов.
