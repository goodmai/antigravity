# Лаба 11: Терминал, безопасность, Turbo

> 🔗 Практика к [Уроку 11](../../lessons/11/README.md) — *Терминал, Безопасность и Turbo*

Настраиваем безопасную работу агента с терминалом и Allow/Deny-списки.

## 🎯 Цель

Закрепить материал Урока 11 через 8 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- Replit — *Create Repl → Import from GitHub*
- Google Cloud Shell — `https://shell.cloud.google.com` → `git clone`

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash

```

## 📋 Задачи

### Задача 1 — Три режима

**Цель:** Сравнить Off/Auto/Turbo.

**Шаги:**
1. `notes/term-modes.md`: риск/скорость каждого.

**Критерий приёмки:** Для каждого режима — сценарий применения.

### Задача 2 — Deny List

**Цель:** Заблокировать опасное.

**Шаги:**
1. Добавь `rm -rf /`, fork-bomb в deny.

**Критерий приёмки:** Запрещённая команда не выполняется.

### Задача 3 — Allow List

**Цель:** Разрешить рутину без подтверждений.

**Шаги:**
1. Добавь `git status`, `npm test`.

**Критерий приёмки:** Разрешённые команды идут без запроса.

### Задача 4 — Auto-подтверждение

**Цель:** Проверить запрос на опасное.

**Шаги:**
1. В Auto создай и удали файл.

**Критерий приёмки:** Удаление потребовало подтверждения.

### Задача 5 — Turbo с чистым деревом

**Цель:** Безопасный массовый рефактор.

**Шаги:**
1. Чистый git → Turbo → массовая замена → diff.

**Критерий приёмки:** Есть путь отката (`git reset`).

### Задача 6 — Inline-команда

**Цель:** Сгенерировать сложный shell.

**Шаги:**
1. `Ctrl+I`: найти лог-файлы за час с ошибкой 500.

**Критерий приёмки:** Сгенерирована корректная `find|grep` цепочка.

### Задача 7 — Аудит политики

**Цель:** Проверить конфиг безопасности.

**Шаги:**
1. Ревью текущих списков, отчёт о дырах.

**Критерий приёмки:** Найдена минимум 1 рекомендация по ужесточению.

### Задача 8 — Инцидент-симуляция

**Цель:** Отработать опасный сценарий.

**Шаги:**
1. Смоделируй попытку деструктивной команды, опиши защиту.

**Критерий приёмки:** Защитный механизм сработал, описан разбор.
