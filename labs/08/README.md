# Лаба 08: Группы задач и агентный режим

> 🔗 Практика к [Уроку 8](../../lessons/8/README.md) — *Агентный Режим и Группы Задач*

Декомпозиция большой цели в группы задач и контроль их выполнения.

## 🎯 Цель

Закрепить материал Урока 8 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- Replit — *Create Repl → Import from GitHub*
- github.dev — открой репозиторий и нажми клавишу **`.`**

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash
# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh
```

## 📋 Задачи

### Задача 1 — Декомпозиция

**Цель:** Разбить цель на задачи.

**Шаги:**
1. Большую фичу разложи в `tasks/plan.md` (8+ задач).

**Критерий приёмки:** Задачи атомарны и независимы где возможно.

### Задача 2 — Группировка

**Цель:** Сгруппировать по зависимостям.

**Шаги:**
1. Отметь группы и порядок.

**Критерий приёмки:** Граф зависимостей корректен.

### Задача 3 — Параллельные ветки

**Цель:** Выделить независимое.

**Шаги:**
1. Помечен пул задач для параллели.

**Критерий приёмки:** Параллельные задачи не конфликтуют.

### Задача 4 — Прогон группы

**Цель:** Выполнить первую группу.

**Шаги:**
1. Запусти агента на группе 1.

**Критерий приёмки:** Группа завершена, статус обновлён.

### Задача 5 — Контроль прогресса

**Цель:** Отслеживать статусы.

**Шаги:**
1. Ведётся чек-лист выполнения.

**Критерий приёмки:** Статусы актуальны после каждой задачи.

### Задача 6 — Переприоритизация

**Цель:** Изменить план на лету.

**Шаги:**
1. Вставь срочную задачу, перестрой план.

**Критерий приёмки:** План пересобран без потери прогресса.

### Задача 7 — Ретроспектива

**Цель:** Сделать выводы.

**Шаги:**
1. `tasks/retro.md`: что ускорить.

**Критерий приёмки:** Выявлены узкие места процесса.
