# Лаба 18: Рефакторинг legacy с агентом

> 🔗 Практика к [Уроку 18](../../lessons/18/README.md) — *Рефакторинг и Legacy*

Безопасный рефакторинг покрытого тестами legacy под контролем агента.

## 🎯 Цель

Закрепить материал Урока 18 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- github.dev — открой репозиторий и нажми клавишу **`.`**
- Replit — *Create Repl → Import from GitHub*

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash
# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh
```

## 📋 Задачи

### Задача 1 — Сетка безопасности

**Цель:** Зафиксировать поведение.

**Шаги:**
1. Покрой legacy-функцию характеризующими тестами.

**Критерий приёмки:** Тесты фиксируют текущее поведение (зелёные).

### Задача 2 — Запах кода

**Цель:** Найти проблемы.

**Шаги:**
1. Агент перечисляет code smells с приоритетом.

**Критерий приёмки:** Список ранжирован по риску.

### Задача 3 — Малый шаг

**Цель:** Безопасное извлечение.

**Шаги:**
1. Extract method, прогон тестов.

**Критерий приёмки:** Поведение не изменилось (тесты зелёные).

### Задача 4 — Развязка зависимостей

**Цель:** Убрать жёсткую связь.

**Шаги:**
1. Введи интерфейс/инъекцию.

**Критерий приёмки:** Модуль тестируется изолированно.

### Задача 5 — Уменьшение сложности

**Цель:** Снизить цикломатику.

**Шаги:**
1. Упростить ветвления.

**Критерий приёмки:** Сложность измеримо снижена.

### Задача 6 — Регресс-защита

**Цель:** Поймать регресс.

**Шаги:**
1. Внеси скрытый баг, тесты ловят.

**Критерий приёмки:** Регресс обнаружен автоматически.

### Задача 7 — Документация решений

**Цель:** Зафиксировать ход.

**Шаги:**
1. `refactor/log.md`: до→после, причина.

**Критерий приёмки:** Каждое изменение обосновано.
