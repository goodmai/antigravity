# Лаба 05: Каталог стандартных скиллов

> 🔗 Практика к [Уроку 5](../../lessons/5/README.md) — *Каталог стандартных скиллов*

Инвентаризация и осмысленное применение встроенных скиллов.

## 🎯 Цель

Закрепить материал Урока 5 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- github.dev — открой репозиторий и нажми клавишу **`.`**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- Replit — *Create Repl → Import from GitHub*

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash
# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh
```

## 📋 Задачи

### Задача 1 — Инвентаризация

**Цель:** Составить карту доступных скиллов.

**Шаги:**
1. Перечисли скиллы из `skills/` в `notes/skill-map.md`.

**Критерий приёмки:** Каждый скилл — назначение в одну строку.

### Задача 2 — init

**Цель:** Применить инициализацию.

**Шаги:**
1. Запусти init на учебном проекте.

**Критерий приёмки:** Создан корректный конфиг.

### Задача 3 — review

**Цель:** Провести ревью изменений.

**Шаги:**
1. Сделай правку и прогони review.

**Критерий приёмки:** Получен структурированный отчёт.

### Задача 4 — security-review

**Цель:** Аудит безопасности.

**Шаги:**
1. Запусти security-review на коде с уязвимостью.

**Критерий приёмки:** Уязвимость найдена и описана.

### Задача 5 — simplify

**Цель:** Упростить код.

**Шаги:**
1. Прогони simplify на раздутом модуле.

**Критерий приёмки:** Код стал проще без потери поведения.

### Задача 6 — Комбинация

**Цель:** Связать 2 скилла в цепочку.

**Шаги:**
1. review → simplify на одном изменении.

**Критерий приёмки:** Цепочка отрабатывает последовательно.

### Задача 7 — Когда не применять

**Цель:** Описать антипаттерны.

**Шаги:**
1. В `notes/skill-map.md` добавь раздел SKIP.

**Критерий приёмки:** Для 3 скиллов указано, когда они вредны.
