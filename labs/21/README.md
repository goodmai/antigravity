Системная диагностика, когда агент «застрял» или делает не то.

## 🎯 Цель

Закрепить материал Урока 21 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- github.dev — открой репозиторий и нажми клавишу **`.`**
- Replit — *Create Repl → Import from GitHub*

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash
# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh
```

## 📋 Задачи

### Задача 1 — Воспроизведение

**Цель:** Стабильно повторить сбой.

**Шаги:**
1. Зафиксируй промпт+контекст, повтори 2 раза.

**Критерий приёмки:** Сбой воспроизводится детерминированно.

### Задача 2 — Сужение контекста

**Цель:** Изолировать причину.

**Шаги:**
1. Убирай части контекста до минимального кейса.

**Критерий приёмки:** Найден минимальный триггер проблемы.

### Задача 3 — Гипотезы

**Цель:** Сформулировать и проверить.

**Шаги:**
1. 3 гипотезы, эксперимент на каждую.

**Критерий приёмки:** Гипотезы подтверждены/опровергнуты данными.

### Задача 4 — Логи рассуждения

**Цель:** Включить пошаговость.

**Шаги:**
1. Попроси план перед действием.

**Критерий приёмки:** Видно, где ломается рассуждение.

### Задача 5 — Контекст-перегруз

**Цель:** Проверить переполнение.

**Шаги:**
1. Сократи контекст, сравни результат.

**Критерий приёмки:** Подтверждено/исключено влияние объёма.

### Задача 6 — Фикс и регресс

**Цель:** Починить и закрепить.

**Шаги:**
1. Исправь, добавь проверку от повтора.

**Критерий приёмки:** Сбой не воспроизводится, есть страховка.

### Задача 7 — Постмортем

**Цель:** Задокументировать.

**Шаги:**
1. `debug/postmortem.md`: причина, фикс, урок.

**Критерий приёмки:** Постмортем переиспользуем командой.
