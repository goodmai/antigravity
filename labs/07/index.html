Лаба 07: QA Architect: qa-skill-tester

🔗 Практика к Уроку 7 — QA Architect

Применяем мета-скилл QA для генерации и сопровождения тест-кейсов.

🎯 Цель

Закрепить материал Урока 7 через 7 практических задач в облачной песочнице GitHub. Каждая задача имеет явный критерий приёмки — лаба считается сданной, когда выполнен финальный чек-лист.

🧪 Песочница (мультиплатформа)

Рекомендуется для этой лабы: GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

  • GitHub Codespaces — https://github.com/goodmai/antigravity → Code ▾ → Codespaces → Create
  • Gitpod — https://gitpod.io/#https://github.com/goodmai/antigravity

  • StackBlitz — https://stackblitz.com/github/goodmai/antigravity

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): ../SANDBOX_SETUP.md.

# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh

📋 Задачи

Задача 1 — Спека под тест

Цель: Описать поведение для покрытия.

Шаги:

  1. Создай spec/login.md с 3 сценариями.

Критерий приёмки: Сценарии однозначны и проверяемы.

Задача 2 — Генерация кейсов

Цель: Сгенерировать тест-кейсы.

Шаги:

  1. qa-skill-tester по spec/login.md.

Критерий приёмки: Получено ≥5 тест-кейсов с предусловиями.

Задача 3 — Негативные кейсы

Цель: Покрыть ошибки.

Шаги:

  1. Добавь кейсы на невалидный ввод.

Критерий приёмки: Есть негативные и граничные кейсы.

Задача 4 — Трассируемость

Цель: Связать кейсы и требования.

Шаги:

  1. Матрица требование→кейс.

Критерий приёмки: Каждое требование покрыто ≥1 кейсом.

Задача 5 — Экспорт

Цель: Перенести кейсы в код.

Шаги:

  1. Сгенерируй тестовые файлы.

Критерий приёмки: Тесты запускаются.

Задача 6 — Регрессия

Цель: Поймать регресс.

Шаги:

  1. Внеси баг, прогони набор.

Критерий приёмки: Регресс пойман нужным кейсом.

Задача 7 — Отчёт QA

Цель: Сводный отчёт качества.

Шаги:

  1. Сгенерируй qa/report.md.

Критерий приёмки: Отчёт: покрытие, риски, рекомендации.
