# Лаба 03: @Mentions и Workflows

> 🔗 Практика к [Уроку 3](../../lessons/3/README.md) — *@ Mentions и Workflows*

Практика адресных упоминаний файлов/символов и сборки повторяемых воркфлоу.

## 🎯 Цель

Закрепить материал Урока 3 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- github.dev — открой репозиторий и нажми клавишу **`.`**
- Replit — *Create Repl → Import from GitHub*

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash
# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh
```

## 📋 Задачи

### Задача 1 — @file

**Цель:** Сфокусировать агента упоминанием файла.

**Шаги:**
1. Создай 2 файла.
2. Через @file попроси изменить только один.

**Критерий приёмки:** Изменён ровно упомянутый файл.

### Задача 2 — @symbol

**Цель:** Адресовать функцию/класс.

**Шаги:**
1. Упомяни конкретную функцию и попроси добавить docstring.

**Критерий приёмки:** Затронут только указанный символ.

### Задача 3 — Свой workflow

**Цель:** Описать многошаговый воркфлоу.

**Шаги:**
1. Создай `.agent/workflows/lint-fix.md` (lint→fix→test).

**Критерий приёмки:** Workflow запускается одной командой.

### Задача 4 — Параметризация

**Цель:** Сделать workflow с аргументом.

**Шаги:**
1. Добавь параметр пути в workflow.

**Критерий приёмки:** Один workflow работает для разных путей.

### Задача 5 — Цепочка mentions

**Цель:** Скомбинировать @file+@symbol.

**Шаги:**
1. Реши задачу, ссылаясь на файл и символ одновременно.

**Критерий приёмки:** Контекст агента ограничен указанным.

### Задача 6 — Workflow в CI-стиле

**Цель:** Сэмулировать пайплайн локально.

**Шаги:**
1. Workflow: format→test→build, выводит отчёт.

**Критерий приёмки:** Отчёт содержит статусы всех шагов.

### Задача 7 — Документация воркфлоу

**Цель:** Описать каталог воркфлоу.

**Шаги:**
1. Создай `.agent/workflows/README.md` с таблицей.

**Критерий приёмки:** Каждый workflow задокументирован.
