# Лаба 16: Мобильная разработка с агентом

> 🔗 Практика к [Уроку 16](../../lessons/16/README.md) — *Мобильная разработка*

Прототип мобильного экрана на Flutter/React Native с hot-reload циклом.

## 🎯 Цель

Закрепить материал Урока 16 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- Replit — *Create Repl → Import from GitHub*
- StackBlitz — `https://stackblitz.com/github/goodmai/antigravity`

## 📋 Задачи

### Задача 1 — Среда

**Цель:** Поднять мобильный стек.

**Шаги:**
1. Установи Flutter ИЛИ Expo в песочнице.

**Критерий приёмки:** `flutter doctor`/`expo --version` ок.

### Задача 2 — Экран логина

**Цель:** Сгенерировать UI.

**Шаги:**
1. Агент пишет экран логина с валидацией.

**Критерий приёмки:** Поля валидируются, ошибки видны.

### Задача 3 — State management

**Цель:** Добавить состояние.

**Шаги:**
1. Provider/Riverpod или hooks для формы.

**Критерий приёмки:** Состояние формы управляемо и тестируемо.

### Задача 4 — Hot-reload цикл

**Цель:** Чинить на лету.

**Шаги:**
1. Внеси баг, агент правит по логу run.

**Критерий приёмки:** Ошибка устранена без перезапуска с нуля.

### Задача 5 — Навигация

**Цель:** Добавить переход.

**Шаги:**
1. Login→Home через роутер.

**Критерий приёмки:** Навигация работает в обе стороны.

### Задача 6 — Адаптивность

**Цель:** Проверить разные экраны.

**Шаги:**
1. Тест на 2 разрешениях.

**Критерий приёмки:** Вёрстка не ломается.

### Задача 7 — Сборка

**Цель:** Собрать артефакт.

**Шаги:**
1. `flutter build web` / `expo export`.

**Критерий приёмки:** Артефакт сборки создан.
