**Цель:** Сбросить состояние.

**Шаги:**
1. Новый чат vs продолжение — сравни.

**Критерий приёмки:** Показано обнуление матрицы внимания.

### Задача 3 — 4 элемента промпта

**Цель:** Собрать структуру.

**Шаги:**

**Критерий приёмки:** Ответ соответствует заданному формату.

### Задача 4 — Эксперимент памяти

**Цель:** Длинный vs новый чат.

**Шаги:**

**Критерий приёмки:** Разница задокументирована.
