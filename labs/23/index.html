Лаба 23: Многоагентная оркестрация

🔗 Практика к Уроку 23 — Многоагентная оркестрация

Координация нескольких агентов: разделение ролей, передача контекста, сборка результата.

🎯 Цель

Закрепить материал Урока 23 через 7 практических задач в облачной песочнице GitHub. Каждая задача имеет явный критерий приёмки — лаба считается сданной, когда выполнен финальный чек-лист.

🧪 Песочница (мультиплатформа)

Рекомендуется для этой лабы: GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

  • GitHub Codespaces — https://github.com/goodmai/antigravity → Code ▾ → Codespaces → Create
  • Gitpod — https://gitpod.io/#https://github.com/goodmai/antigravity
  • Replit — Create Repl → Import from GitHub
  • Google Cloud Shell — https://shell.cloud.google.com → git clone

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): ../SANDBOX_SETUP.md.

# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh

📋 Задачи

Задача 1 — Роли

Цель: Спроектировать состав.

Шаги:

  1. orchestration/roles.md: 3 роли и зоны ответственности.

Критерий приёмки: Роли не пересекаются по ответственности.

Задача 2 — Контракт обмена

Цель: Формат передачи.

Шаги:

  1. Опиши схему сообщения между агентами.

Критерий приёмки: Схема однозначна и валидируема.

Задача 3 — Параллель

Цель: Запустить независимое.

Шаги:

  1. 2 агента на независимых подзадачах.

Критерий приёмки: Нет конфликтов, результаты независимы.

Задача 4 — Слияние

Цель: Собрать общий результат.

Шаги:

  1. Агент-сборщик объединяет выводы.

Критерий приёмки: Итог консистентен, конфликты разрешены.

Задача 5 — Супервизор

Цель: Контроль качества.

Шаги:

  1. Ревью-агент проверяет результат.

Критерий приёмки: Низкокачественный результат отклоняется.

Задача 6 — Сбой агента

Цель: Обработать отказ.

Шаги:

  1. Сэмулируй падение одного агента.

Критерий приёмки: Система деградирует штатно, не падает целиком.

Задача 7 — Трассировка

Цель: Сквозной trace.

Шаги:

  1. Единый id через всех агентов.

Критерий приёмки: Путь задачи восстанавливается по trace.
