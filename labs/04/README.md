# Лаба 04: Создание Agent Skill

> 🔗 Практика к [Уроку 4](../../lessons/4/README.md) — *Навыки Агента (Agent Skills)*

Собираем собственный переиспользуемый скилл агента с нуля.

## 🎯 Цель

Закрепить материал Урока 4 через 7 практических задач в облачной
песочнице GitHub. Каждая задача имеет явный **критерий приёмки** — лаба
считается сданной, когда выполнен финальный чек-лист.

## 🧪 Песочница (мультиплатформа)

**Рекомендуется для этой лабы:** GitHub Codespaces — полноценный Linux + Docker + GitHub PR-флоу, универсальна для любой задачи.

Любую задачу можно выполнить в одной из песочниц (быстрый запуск):

- GitHub Codespaces — `https://github.com/goodmai/antigravity` → **Code ▾ → Codespaces → Create**
- Gitpod — `https://gitpod.io/#https://github.com/goodmai/antigravity`
- Replit — *Create Repl → Import from GitHub*
- github.dev — открой репозиторий и нажми клавишу **`.`**

Полная шпаргалка (bootstrap-скрипт, devcontainer, секреты, выбор платформы): **[../SANDBOX_SETUP.md](../SANDBOX_SETUP.md)**.

```bash
# единый вход в любой песочнице
bash scripts/sandbox-bootstrap.sh
```

## 📋 Задачи

### Задача 1 — Анатомия скилла

**Цель:** Разобрать структуру существующего скилла.

**Шаги:**
1. Изучи каталог `skills/`.
2. Опиши обязательные части в `notes/skill-anatomy.md`.

**Критерий приёмки:** Описаны манифест, триггеры, инструкции.

### Задача 2 — Манифест

**Цель:** Создать каркас своего скилла.

**Шаги:**
1. Создай `skills/my-skill/SKILL.md` с метаданными.

**Критерий приёмки:** Скилл виден агенту по имени.

### Задача 3 — Триггеры

**Цель:** Настроить условия запуска.

**Шаги:**
1. Опиши TRIGGER/SKIP правила.

**Критерий приёмки:** Скилл активируется только в нужном контексте.

### Задача 4 — Логика

**Цель:** Наполнить инструкции скилла.

**Шаги:**
1. Реализуй конкретную пользу (например, генератор changelog).

**Критерий приёмки:** Скилл выполняет полезную работу end-to-end.

### Задача 5 — Тест скилла

**Цель:** Проверить на реальной задаче.

**Шаги:**
1. Запусти скилл на учебном репозитории.

**Критерий приёмки:** Результат соответствует ожиданию.

### Задача 6 — Идемпотентность

**Цель:** Убедиться в безопасности повторного запуска.

**Шаги:**
1. Запусти скилл дважды.

**Критерий приёмки:** Повторный запуск не ломает состояние.

### Задача 7 — Публикация

**Цель:** Подготовить к шарингу.

**Шаги:**
1. Добавь README и пример использования.

**Критерий приёмки:** Скилл готов к PR.
